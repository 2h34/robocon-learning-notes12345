# 4. Frame、向量与坐标

## 4.1 Frame

**Frame = Reference Frame / Coordinate Frame，参考坐标系 / 坐标系。**

它回答：

> “我用哪一套坐标轴描述这个空间量？”

机器人中常见：

- World Frame：世界坐标系 \(W\)
- Body Frame：机体坐标系 \(B\)
- IMU Frame：IMU 自身坐标系

---

## 4.2 向量本身 ≠ 向量坐标

一个空间中的物理向量记作：

\[
\mathbf p
\]

在不同坐标系下可以写成：

\[
\mathbf p_W
\]

和：

\[
\mathbf p_B
\]

即使：

\[
\mathbf p_W\neq\mathbf p_B
\]

也不意味着物理向量 \(\mathbf p\) 本身改变。

### 今日理解

如果机器人发生旋转：

- 空间中一个固定向量本身可以不变；
- 但它在 Body Frame 下的坐标会变化。

用户回答：

> **发生变化的是向量在 Body Frame 下的坐标表示。**

理解正确。

# 5. Rotation Matrix 快速回顾

## 5.1 坐标变换

采用：

\[
\mathbf p_W=R_{WB}\mathbf p_B
\]

则：

\[
\boxed{
R_{WB}:B\rightarrow W
}
\]

即：

> 把 Body Frame 下的坐标转换成 World Frame 下的坐标。

反方向：

\[
R_{BW}=R_{WB}^{-1}
\]

对于 Rotation Matrix：

\[
R^{-1}=R^T
\]

因此：

\[
\boxed{
R_{BW}=R_{WB}^T
}
\]

并有：

\[
\mathbf p_B=R_{BW}\mathbf p_W
\]

### 今日自测

用户能够正确判断：

- \(R_{WB}\)：B → W
- \(R_{BW}\)：W → B

说明 Frame 方向基础已经重新激活。

}

合计：

\[

\]

# 8. Rotation Matrix

## 8.1 基本约束

三维旋转矩阵：

\[
R\in\mathbb R^{3\times3}
\]

必须满足：

\[
\boxed{
R^TR=I
}
\]

以及：

\[
\boxed{
\det(R)=1
}
\]

所有合法三维旋转矩阵组成：

\[
\boxed{
SO(3)
}
\]

其中：

**SO(3) = Special Orthogonal Group，三维特殊正交群。**

Day 1 暂时只需要知道：

> SO(3) 是所有合法三维 Rotation Matrix 的集合。

李群、李代数留到 Day 2。

---

## 8.2 为什么 9 个元素只有 3 个自由度？

一个普通 \(3\times3\) Matrix 有 9 个数。

但 Rotation Matrix 的 9 个数不能独立变化，因为：

- 列向量长度必须为 1；
- 不同列必须互相正交；
- \(\det(R)=1\)。

所以：

\[
\boxed{
9\text{ 个参数}
}
\]

但只有：

\[
\boxed{
3\text{ 个旋转自由度}
}
\]

因此 Rotation Matrix 是一种冗余表示。

---

## 8.3 今日错误：正交矩阵 vs 正定矩阵

用户最初说：

> “旋转矩阵需要满足正定矩阵和行列式等于一的条件。”

核心思想是对的：

> Rotation Matrix 受到约束，所以 9 个量不等于 9 DOF。

但术语需要纠正。

正确是：

\[
\boxed{
\text{正交矩阵}
}
\]

不是：

\[
\boxed{
\text{正定矩阵}
}
\]

### 正交矩阵

满足：

\[
R^TR=I
\]

### 正定矩阵

通常指：

\[
x^TAx>0,\qquad x\neq0
\]

二者是完全不同的概念。

# 9. Rotation Vector / Axis-Angle

## 9.1 Axis-Angle

**Axis-Angle = 轴角表示**

任意三维 Rotation 可以描述成：

- 绕单位轴 \(\mathbf n\)；
- 转动角度 \(\theta\)。

其中：

\[
\|\mathbf n\|=1
\]

---

## 9.2 Rotation Vector

定义：

\[
\boxed{
\boldsymbol\phi=\theta\mathbf n
}
\]

其中：

\[
\boldsymbol\phi\in\mathbb R^3
\]

称为 **Rotation Vector，旋转向量**。

核心直觉：

\[
\boxed{
\text{方向}=\text{旋转轴}
}
\]

\[
\boxed{
\text{长度}=\text{旋转角}
}
\]

所以：

\[
\theta=\|\boldsymbol\phi\|
\]

\[
\mathbf n=
\frac{\boldsymbol\phi}{\|\boldsymbol\phi\|}
\]

---

## 9.3 示例 1

\[
\boldsymbol\phi=
\begin{bmatrix}
\pi/2\\
0\\
0
\end{bmatrix}
\]

表示：

\[
\boxed{
\text{绕 }X\text{ 轴旋转 }90^\circ
}
\]

用户回答正确。

---

## 9.4 示例 2：不能当成三个 Euler Angle

\[
\boldsymbol\phi=
\begin{bmatrix}
1\\
1\\
0
\end{bmatrix}
\]

不能理解成：

> 先绕 X 轴转 1 rad，再绕 Y 轴转 1 rad。

正确是：

旋转角：

\[
\theta=
\sqrt{1^2+1^2}
=
\sqrt2
\]

旋转轴：

\[
\mathbf n=
\frac1{\sqrt2}
\begin{bmatrix}
1\\
1\\
0
\end{bmatrix}
\]

所以表示：

\[
\boxed{
\text{绕 }[1,1,0]^T\text{ 对应的单位方向旋转 }\sqrt2\text{ rad}
}
\]

### 用户理解

用户能够使用：

\[
\phi=\theta n
\]

解释：

> 因为 \(n\) 是单位向量，所以 \(\|\phi\|=\theta\)。

---

## 9.5 Rotation Vector ↔ Rotation Matrix

两者可以互相转换：

\[
\boxed{
\text{Rotation Vector}
\leftrightarrow
\text{Rotation Matrix}
}
\]

Rotation Vector → Rotation Matrix 可通过 Rodrigues Formula。

Day 1 不要求推导 Rodrigues Formula。

\[
\delta\theta\in\mathbb R^3
\]

今天先建立直觉：

\[
\boxed{
\delta\theta
\text{ 可以看作一个“小旋转向量”}
}
\]

# 10. Euler Angle / Roll-Pitch-Yaw

## 10.1 Euler Angle

**Euler Angle = 欧拉角**

通过三次有顺序的单轴旋转表示一个三维 Rotation。

今日主要采用：

\[
\boxed{
ZYX
}
\]

也就是：

\[
\boxed{
yaw-pitch-roll
}
\]

写成 Rotation Matrix：

\[
\boxed{
R=R_z(\psi)R_y(\theta)R_x(\phi)
}
\]

其中：

- \(\phi\)：Roll
- \(\theta\)：Pitch
- \(\psi\)：Yaw

---

## 10.2 Roll / Pitch / Yaw 直觉

当前坐标约定：

- \(X\)：前；
- \(Y\)：右；
- \(Z\)：上。

因此：

- Roll：绕 \(X\)
- Pitch：绕 \(Y\)
- Yaw：绕 \(Z\)

### 今日场景题

机器人保持水平，只在地面原地改变朝向：

\[
\boxed{
Yaw\text{ 变化}
}
\]

用户正确回答：

> C，因为绕 Z 轴转了。

# 11. 三维 Rotation 不满足交换律

一般：

\[
\boxed{
R_1R_2\neq R_2R_1
}
\]

因此：

> 先绕 X，再绕 Y

和：

> 先绕 Y，再绕 X

一般最终姿态不同。

### 用户总结

> “一般不同，与旋转顺序有关。”

理解正确。

这个知识后面直接用于 Quaternion multiplication。

# 12. Gimbal Lock

## 12.1 定义

**Gimbal Lock = 万向锁**

对于今日采用的 ZYX Euler Angle：

\[
\boxed{
Pitch=\pm90^\circ
}
\]

时会出现参数化奇异。

---

## 12.2 本质

不是机器人真的失去一个旋转自由度。

真实刚体仍然：

\[
\boxed{
3\text{ rotational DOF}
}
\]

出问题的是：

\[
\boxed{
Euler Angle 参数化
}
\]

在奇异位置，原本应当独立的两个旋转方向发生退化。

### 用户理解

用户总结：

> “在这个参数化点附近，可能出现改变不同的两个轴，但产生重复的旋转效果。”

经进一步精确后：

> 真实刚体没有少自由度，只是 ZYX Euler Angle 在该姿态下无法独立地区分全部旋转方向。

---

## 12.3 为什么不适合作为内部滤波状态？

在奇异位置附近：

- 小的真实姿态变化；
- 可能对应很大的 Euler 数值变化；
- 连续传播和滤波变得不稳定。

因此：

\[
\boxed{
Euler Angle 适合看，不适合长期作为内部姿态状态
}
\]

# 16. Unit Quaternion

## 16.1 定义

表示 Rotation 的 Quaternion 要满足：

\[
\boxed{
\|q\|=1
}
\]

即：

\[
\boxed{
q_x^2+q_y^2+q_z^2+q_w^2=1
}
\]

---

## 16.2 为什么 4 个参数只有 3 DOF？

Quaternion 看起来有 4 个参数：

\[
q_x,q_y,q_z,q_w
\]

但存在一个独立约束：

\[
q_x^2+q_y^2+q_z^2+q_w^2=1
\]

因此：

\[
\boxed{
4-1=3
}
\]

最终只有 3 个独立 Rotation DOF。

### 用户总结

> “因为有一个平方和为 1 的约束条件，会减少一个自由度。”

理解正确。

# 17. Quaternion Multiplication

## 17.1 物理意义

\[
\boxed{
q_1\otimes q_2
}
\]

表示两个 Rotation 的复合。

这和 Rotation Matrix 的：

\[
R_1R_2
\]

高度对应。

---

## 17.2 旋转顺序

在今日采用的主动旋转 convention 下：

如果：

1. 先执行 \(q_x\)
2. 再执行 \(q_y\)

则：

\[
\boxed{
q_{\text{total}}
=
q_y\otimes q_x
}
\]

### 用户理解

> “先进行的放在右边。”

正确。

---

## 17.3 不满足交换律

一般：

\[
\boxed{
q_1\otimes q_2\neq q_2\otimes q_1
}
\]

这和三维 Rotation 本身的顺序性完全对应。

# 18. Quaternion Conjugate / Inverse

## 18.1 Conjugate

若：

\[
q=[\mathbf v,w]
\]

则：

\[
\boxed{
q^*=[-\mathbf v,w]
}
\]

即：

\[
q^*=
[-q_x,-q_y,-q_z,q_w]
\]

---

## 18.2 Inverse

一般 Quaternion：

\[
\boxed{
q^{-1}
=
\frac{q^*}{\|q\|^2}
}
\]

如果：

\[
\|q\|=1
\]

则：

\[
\boxed{
q^{-1}=q^*
}
\]

---

# 19. 今日重点问题：Inverse 公式是怎么来的？

用户主动追问：

> “\(q^{-1}=q^*/\|q\|^2\) 这个公式是怎么来的？”

推导核心如下。

Quaternion 与其共轭相乘：

\[
q\otimes q^*
\]

虚部抵消，实部得到：

\[
\|q\|^2
\]

因此：

\[
\boxed{
q\otimes q^*
=
\|q\|^2
}
\]

而 inverse 要满足：

\[
q\otimes q^{-1}=1
\]

所以：

\[
q\otimes
\frac{q^*}{\|q\|^2}
=
\frac{q\otimes q^*}{\|q\|^2}
=
1
\]

因此：

\[
\boxed{
q^{-1}
=
\frac{q^*}{\|q\|^2}
}
\]

对于 Unit Quaternion：

\[
\boxed{
q^{-1}=q^*
}
\]

---

## 19.1 Inverse 的物理意义

如果：

\[
q
\]

表示绕某轴：

\[
+\theta
\]

那么：

\[
q^{-1}
\]

表示：

\[
\boxed{
-\theta
}
\]

例如：

\[
Y\text{ 轴 }+30^\circ
\]

的 inverse 表示：

\[
\boxed{
Y\text{ 轴 }-30^\circ
}
\]

用户回答正确。

# 20. \(q\) 和 \(-q\)

## 20.1 Double Cover

Quaternion 表示 Rotation 时：

\[
\boxed{
q\equiv -q
}
\]

即：

> \(q\) 与 \(-q\) 表示同一个三维 Rotation。

这叫：

**Double Cover = 双覆盖。**

---

# 21. 今日重点困惑：为什么 \(-q\) 不是反向 Rotation？

用户提出：

> “既然姿态没变，为什么角度会反方向转？”

这是今天一个非常重要的理解节点。

必须区分：

\[
q
\]

\[
q^{-1}
\]

\[
-q
\]

---

## 21.1 \(q^{-1}\)

对于 Unit Quaternion：

\[
q^{-1}=[-\mathbf v,w]
\]

只有虚部变号。

它表示：

\[
\boxed{
\text{反向 Rotation}
}
\]

即：

\[
+\theta\rightarrow-\theta
\]

---

## 21.2 \(-q\)

\[
-q=[-\mathbf v,-w]
\]

四个分量全部变号。

它表示：

\[
\boxed{
\text{同一个 Rotation 的另一个 Quaternion 表示}
}
\]

因此：

\[
\boxed{
q^{-1}\neq -q
}
\]

---

## 21.3 Axis-Angle 直觉

因为：

\[
q(\theta)=
\left[
n\sin\frac{\theta}{2},
\cos\frac{\theta}{2}
\right]
\]

而：

\[
q(\theta+2\pi)
=
-q(\theta)
\]

真实三维 Rotation 则满足：

\[
R(\theta+2\pi)=R(\theta)
\]

因此：

\[
\boxed{
q\text{ 和 }-q
\text{最终对应同一个空间姿态}
}
\]

用户随后总结：

这个理解在“实际运动路径”层面可以成立，例如：

- 转 \(90^\circ\)
- 转 \(450^\circ\)

真实转动过程不同，但最终 Orientation 相同。

> **\(q\) 和 \(-q\) 不是两个不同 Rotation，而是同一个 Rotation 的两个 Quaternion 表示。**

# 22. Quaternion 旋转三维向量

## 22.1 Pure Quaternion

三维向量：

\[
\mathbf p=
\begin{bmatrix}
p_x\\p_y\\p_z
\end{bmatrix}
\]

按照题目二 `[x,y,z,w]` convention 嵌入：

\[
\boxed{
p=[p_x,p_y,p_z,0]
}
\]

这叫：

**Pure Quaternion = 纯四元数 / 纯虚四元数。**

---

## 22.2 旋转公式

\[
\boxed{
p'
=
q\otimes p\otimes q^{-1}
}
\]

结果仍是纯 Quaternion。

取前三个分量，就是旋转后的三维向量。

---

## 22.3 与 Rotation Matrix 对应

Rotation Matrix：

\[
\boxed{
\mathbf p'=R\mathbf p
}
\]

Quaternion：

\[
\boxed{
p'=q p q^{-1}
}
\]

二者做的是同一个 Rotation。

## 22.4 今日自测

\end{bmatrix}

则 Pure Quaternion：

\[
\boxed{
p=(1,0,0,0)
}
\]

若 \(q\) 表示绕 \(Z\) 轴旋转 \(90^\circ\)，则：

\[
\boxed{
X^+\rightarrow Y^+
}
\]

用户两个回答均正确。

# 23. 用户的重要直觉：Quaternion 很像 Matrix

用户提出：

这个感觉在 Rotation 运算层面非常有价值。

| Rotation Matrix | Quaternion | 物理意义 |
|---|---|---|
| \(R\) | \(q\) | 表示 Rotation |
| \(R_2R_1\) | \(q_2\otimes q_1\) | Rotation 复合 |
| \(R^{-1}=R^T\) | \(q^{-1}=q^*\)（单位 q） | 反向 Rotation |
| \(R p\) | \(q p q^{-1}\) | 旋转向量 |
| \(R^TR=I,\det R=1\) | \(\|q\|=1\) | 合法 Rotation 约束 |
| 9 参数 / 3 DOF | 4 参数 / 3 DOF | 冗余表示 |

Quaternion **不是 Matrix**。

\boxed{

\]

# 29. Quaternion 连续数据的符号问题

由于：

\[
q\equiv -q
\]

连续姿态数据可能出现：

\[
q_k
\]

突然换成：

\[
-q_k
\]

即使真实姿态几乎没变。

因此：

\[
\boxed{
\text{Quaternion 四个分量变化很大}
\not\Rightarrow
\text{真实姿态变化很大}
}
\]

---

## 29.1 常见工程处理

对连续两个单位 Quaternion：

\[
q_{k-1},q_k
\]

计算：

\[
d=q_{k-1}^Tq_k
\]

如果：

\[
d<0
\]

则：

\[
\boxed{
q_k\leftarrow -q_k
}
\]

从 \(q_k\) 与 \(-q_k\) 两个等价表示中选择离上一帧更近的一个。

### 注意

这不是改变姿态。

只是：

\[
\boxed{
\text{统一 Quaternion 的符号分支，使数值序列更连续}
}
\]

不是。

\[
\phi=\theta n
\]

三个分量共同描述：

- 一个 Rotation Angle。
