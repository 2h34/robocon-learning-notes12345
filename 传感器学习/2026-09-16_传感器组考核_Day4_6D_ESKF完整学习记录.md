f/h

\[
F/H
\]

负责描述局部小误差如何传播。

# 三、为什么普通 Additive EKF 不适合直接处理 Quaternion

如果直接把状态写成：

\[
x=
\begin{bmatrix}
q\\
b_g
\end{bmatrix}
\]

并做普通加法更新：

\[
q^+=q^-+\delta q
\]

会出现问题：

## 1. Quaternion 有单位约束

\[
\|q\|=1
\]

四个 scalar 并不是四个独立自由度。

## 2. Rotation 只有 3 DOF

Quaternion 用 4 个 scalar 表示旋转，但实际旋转自由度只有 3。

## 3. \(q\equiv -q\)

同一个 Rotation 可以由：

\[
q
\]

和：

\[
-q
\]

共同表示。

因此 Quaternion 的四个分量差并不等价于真实姿态误差。

## 4. 姿态差应该用 Relative Rotation 表示

真正的姿态误差应写成：

\[
q_{\text{rel}}
=
q_1^{-1}\otimes q_2
\]

或者：

\[
R_{\text{rel}}
=
R_1^T R_2
\]

而不是：

\[
q_2-q_1
\]

因此，当前题目选择 ESKF。

# 四、ESKF 的核心：Nominal State + Error State

ESKF = Error-State Extended Kalman Filter（误差状态扩展卡尔曼滤波）。

它本质上仍然是 EKF，只是状态组织方式不同。

## 1. Nominal State

当前题目的 Nominal State：

\[
\boxed{
\hat x=
(\hat q,\hat b_g)
}
\]

其中：

- \(\hat q\)：当前姿态估计；
- \(\hat b_g\)：当前 Gyro Bias estimate。

Quaternion 用 4 个 scalar 表示，Bias 用 3 个 scalar，因此 Nominal State 存储上是 7 个 scalar。

## 2. Error State

定义：

\[
\boxed{
\delta x=
\begin{bmatrix}
\delta\theta\\
\delta b_g
\end{bmatrix}
\in\mathbb R^6
}
\]

其中：

- \(\delta\theta\in\mathbb R^3\)：Attitude Error Rotation Vector（姿态误差旋转向量）；
- \(\delta b_g\in\mathbb R^3\)：Gyro Bias Error（陀螺零偏误差）。

因此：

\[
P\in\mathbb R^{6\times6}
\]

描述的是 Error State 的 covariance，而不是 Quaternion 四个分量或 Rotation Matrix 9 个元素的 covariance。

展开：

\[
P=
\begin{bmatrix}
P_{\theta\theta}&P_{\theta b}\\
P_{b\theta}&P_{bb}
\end{bmatrix}
\]

含义：

- \(P_{\theta\theta}\)：姿态误差 covariance；
- \(P_{bb}\)：Bias Error covariance；
- \(P_{\theta b},P_{b\theta}\)：姿态误差与 Bias Error 的 cross covariance。

---

# 五、Right Multiplicative Error（右乘姿态误差）

本次统一采用：

\[
\boxed{
R_{\text{true}}
=
\hat R\,\delta R
}
\]

Quaternion 形式：

\[
\boxed{
q_{\text{true}}
=
\hat q\otimes\delta q
}
\]

这里的 \(\delta R\) / \(\delta q\) 是相对于当前 Nominal Body-local Frame 定义的小旋转误差。

因此 \(\delta\theta\) 也是在当前 Body-local Frame 中表达。

小角度时：

\[
\boxed{
\delta q
\approx
\begin{bmatrix}
\frac12\delta\theta\\
1
\end{bmatrix}
}
\]

这一 convention 一旦确定，后面的：

- Error Dynamics；
- \(F_c\)；
- \(G_c\)；
- residual；
- Injection；
- Reset；

都必须保持一致。

# 六、Nominal Prediction（标称状态预测）

## 1. Bias Compensation

Gyroscope 测量：

\[
\omega_m
=
\omega_{\text{true}}+b_g+n_g
\]

Nominal Prediction 使用当前 Bias estimate：

\[
\boxed{
\hat\omega
=
\omega_m-\hat b_g
}
\]

## 2. 一帧内姿态增量

\[
\boxed{
\Delta\theta
=
\hat\omega\Delta t
}
\]

再转换成 Quaternion increment：

\[
\Delta\theta\rightarrow\Delta q
\]

## 3. 右乘更新 Quaternion

\[
\boxed{
\hat q_k^-
=
\hat q_{k-1}^+
\otimes
\Delta q
}
\]

随后 Normalize：

\[
\hat q_k^-
\leftarrow
\frac{\hat q_k^-}{\|\hat q_k^-\|}
\]

## 4. Nominal Bias Prediction

当前采用：

\[
\dot{\hat b}_g=0
\]

因此：

\[
\boxed{
\hat b_{g,k}^-=
\hat b_{g,k-1}^+
}
\]

注意：

这不代表真实 \(b_g\) 不变，而是 Nominal Prediction 中 Bias 的均值没有确定性变化项。

# 七、Bias Random Walk 与 \(n_g,n_{bg}\) 的区别

真实 Bias 建模为：

\[
\boxed{
\dot b_g=n_{bg}
}
\]

其中：

\[
n_{bg}
\]

是 Bias Random Walk Driving Noise（零偏随机游走驱动噪声）。

重要纠正：

- \(n_g\)：Gyro Measurement Noise，直接污染当前角速度测量；
- \(n_{bg}\)：驱动 Bias Random Walk；
- 真正缓慢漂移的是 \(b_g\)，不是简单把 \(n_{bg}\) 称为“慢噪声”。

定义 Bias Error：

\[
\boxed{
\delta b_g=b_g-\hat b_g
}
\]

因为：

\[
\dot{\hat b}_g=0
\]

所以：

\[
\boxed{
\dot{\delta b_g}=n_{bg}
}
\]

---

# 八、完整姿态 Error Dynamics

这是 Day4 最关键的公式之一。

最终正式模型：

\[
\boxed{
\dot{\delta\theta}
=
-[\hat\omega]_\times\delta\theta
-\delta b_g
-n_g
}
\]

以及：

\[
\boxed{
\dot{\delta b_g}=n_{bg}
}
\]

## 1. \(-[\hat\omega]_\times\delta\theta\)

含义：

> 已经存在的姿态误差，是在当前 Body-local Frame 中表达的；而这个局部坐标系会随着 Nominal Attitude 旋转，因此已有误差的三个坐标分量也会变化。

它不是新的误差来源，而是已有误差在旋转局部坐标中的“坐标输运”。

直观例子：

原本误差在 Body \(x\) 方向：

\[
\delta\theta=
\begin{bmatrix}
1^\circ\\0\\0
\end{bmatrix}
\]

如果 Body Frame 绕 \(z\) 轴转动，同一个空间小误差在新的 Body Frame 中可能逐渐变成：

\[
\begin{bmatrix}
0\\-1^\circ\\0
\end{bmatrix}
\]

因此该项必须存在。

## 2. \(-\delta b_g\)

Bias estimate 错误会导致：

\[
\hat\omega
\]

与真实角速度不同。

因此：

\[
\delta b_g
\rightarrow
\text{Angular Velocity Error}
\rightarrow
\text{Attitude Error}
\]

并且会随时间积分累积。

## 3. \(-n_g\)

Gyroscope Measurement Noise 直接污染姿态传播，因此进入姿态误差变化率。

# 九、从 Error Dynamics 得到 \(F_c\)

定义：

\[
\boxed{
F_c=
\frac{\partial\dot{\delta x}}
{\partial\delta x}
}
\]

它描述：

\[
\boxed{
\delta x
\rightarrow
\dot{\delta x}
}
\]

完整：

\[
\boxed{
F_c=
\begin{bmatrix}
-[\hat\omega]_\times&-I\\
0&0
\end{bmatrix}
}
\]

四个块分别表示：

1. 左上：
   \[
   -[\hat\omega]_\times
   \]
   姿态误差因旋转坐标系而变化；

2. 右上：
   \[
   -I
   \]
   Bias Error 驱动 Attitude Error；

3. 左下：
   \[
   0
   \]
   姿态误差不直接决定 Bias Random Walk；

4. 右下：
   \[
   0
   \]
   当前 Bias Error 没有确定性的自演化项。

w=

\[
\boxed{
\dot{\delta x}

# 十一、Continuous Process Noise Covariance \(Q_c\)

如果暂时认为三个轴噪声强度相同且互相独立：

\[
\boxed{
Q_c=
\begin{bmatrix}
\sigma_g^2I&0\\
0&\sigma_{bg}^2I
\end{bmatrix}
}
\]

其中：

- \(\sigma_g^2\)：Gyro Measurement Noise 强度；
- \(\sigma_{bg}^2\)：Bias Random Walk Driving Noise 强度。

理解：

\[
\boxed{
Q_c=\text{连续时间噪声统计强度}
}
\]

不是一帧直接加到 \(P\) 里的矩阵。

# 十二、Continuous → Discrete

## 1. \(F_c\) 与 \(\Phi\)

\(F_c\) 描述：

\[
\delta x\rightarrow\dot{\delta x}
\]

而程序逐帧运行，需要：

\[
\delta x_{k-1}\rightarrow\delta x_k
\]

因此定义 State Transition Matrix：

\[
\boxed{
\Phi
}
\]

一阶 Taylor Approximation：

\[
\boxed{
\Phi
\approx
I+F_c\Delta t
}
\]

于是：

\[
\boxed{
\Phi
\approx
\begin{bmatrix}
I-[\hat\omega]_\times\Delta t&-I\Delta t\\
0&I
\end{bmatrix}
}
\]

此前曾用 \(F_k\) 表示同一个离散状态转移概念，后续统一采用 \(\Phi\)，避免与 \(F_c\) 混淆。

## 2. \(Q_c\rightarrow Q_d\)

\[
\boxed{
Q_c
\xrightarrow{G_c,\Delta t,\text{离散化}}
Q_d
}
\]

其中：

\[
Q_d
\]

表示一帧内真正累计形成的 Process Noise Covariance。

完整积分形式只需知道存在，不要求独立推导。

当前掌握一阶近似：

\[
\boxed{
Q_d
\approx
G_cQ_cG_c^T\Delta t
}
\]

## 3. Covariance Prediction

最终：

\[
\boxed{
P_k^-
=
\Phi P_{k-1}^+\Phi^T+Q_d
}
\]

理解：

\[
\boxed{
P^-=
\text{旧不确定性的传播}
+
\text{这一帧新增的不确定性}
}
\]

# 十四、FAST-LIO Observation：从 Quaternion 得到 Residual

Prediction 得到：

\[
\hat q_k^-
\]

FAST-LIO 提供：

\[
q_{obs,k}
\]

## 1. Quaternion 双覆盖处理

因为：

\[
q\equiv -q
\]

若：

\[
\hat q_k^-\cdot q_{obs,k}<0
\]

则：

\[
q_{obs,k}\leftarrow -q_{obs,k}
\]

这只是统一 Quaternion 表示，不改变实际姿态。

## 2. Relative Quaternion

根据右乘误差定义：

\[
q_{obs}
\approx
\hat q^-\otimes\delta q_{obs}
\]

所以：

\[
\boxed{
\delta q_{obs}
=
(\hat q^-)^{-1}\otimes q_{obs}
}
\]

它描述：

> 从当前 Prediction 到 FAST-LIO Observation 还差多少旋转。

## 3. Relative Quaternion → Rotation Vector

可直接根据：

\[
\delta q=
\begin{bmatrix}
n\sin(\theta/2)\\
\cos(\theta/2)
\end{bmatrix}
\]

反解 \(\theta,n\)，再得到：

\[
\boxed{
\delta\theta_{obs}=\theta n
}
\]

也可等价地：

\[
\delta q_{obs}
\leftrightarrow
\delta R_{obs}
\]

然后：

\[
\delta\theta_{obs}
=
\Log(\delta R_{obs})^\vee
\]

当前不需要掌握 Quaternion ↔ Rotation Matrix 的详细运算，只需知道它们描述同一个 Relative Rotation，可以相互转换。

最终：

\[
\boxed{
r_\theta=\delta\theta_{obs}
}
\]

# 十六、Observation Noise Covariance \(R\)

定义：

\[
\boxed{
R=\operatorname{Cov}(v)
}
\]

题目提供 FAST-LIO pose covariance，并要求使用姿态对角项：

\[
cov_{33},\quad cov_{44},\quad cov_{55}
\]

因此：

\[
\boxed{
R=
\operatorname{diag}
(cov_{33},cov_{44},cov_{55})
}
\]

它表示 FAST-LIO 这次姿态 Observation 有多可信。

理解：

\[
R\text{ 大}
\Rightarrow
\text{Observation 不可靠}
\]

\[
R\text{ 小}
\Rightarrow
\text{Observation 更可靠}
\]

严格几何上 RPY covariance 与 Rotation Vector covariance 并非任意姿态下完全等价；当前按题目要求，在小误差局部线性条件下使用。

# 二十、Error Injection

## 1. 姿态 Injection

先：

\[
\delta\hat\theta
\rightarrow
\delta\hat q
\]

完整：

\[
\delta\hat q=
\begin{bmatrix}
n\sin(\theta/2)\\
\cos(\theta/2)
\end{bmatrix}
\]

小角度：

\[
\delta\hat q
\approx
\begin{bmatrix}
\frac12\delta\hat\theta\\
1
\end{bmatrix}
\]

按照右乘 convention：

\[
\boxed{
\hat q^+
=
\hat q^-\otimes\delta\hat q
}
\]

随后 Normalize。

## 2. Bias Injection

因为：

\[

# 二十四、为什么一帧里 \(P\) 会“变三次”

## 第二次：Observation Update

> 第二次计算得到的 \(P_{\text{upd}}\) 是相对于旧 Error reference 的 covariance；第三次 Reset 是进行 reference / error coordinate 的转换。

这一理解正确。

**不得作为当前题目的正式模型使用。**

正式：

0&0
\end{bmatrix}

## 问题 3：一开始不理解 \(-[\hat\omega]_\times\delta\theta\) 为什么存在

最终理解：

因此：

\[

描述的是已有姿态误差的 coordinate transport，而不是新的误差来源。

第三步不是再次融合 Observation。

## 问题 7：一度不清楚 \(P\) 描述 \(R\) 还是 \(\delta R\)

所以 \(P\) 描述的是姿态 **Error State** 的 uncertainty，而不是 Nominal Rotation Matrix \(R\) 本身的 covariance。
