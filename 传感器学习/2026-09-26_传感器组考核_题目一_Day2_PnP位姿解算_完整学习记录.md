# 二、模块 A：PnP 问题建立与坐标系

## 2.1 Object Frame 与 Camera Frame

定义：

- \(O\)：Object Frame，目标坐标系；
- \(C\)：Camera Frame，相机坐标系。

目标坐标系中的三维点：

\[
P_O=
\begin{bmatrix}
X_O\\Y_O\\Z_O
\end{bmatrix}
\]

经过刚体变换后，在相机坐标系中的坐标为：

\[
\boxed{P_C=R_{CO}P_O+t_{CO}}
\]

其中：

- \(R_{CO}\)：把 Object Frame 中的坐标旋转到 Camera Frame；
- \(t_{CO}\)：**目标坐标系原点在相机坐标系中的坐标**。

如果 \(P_O=0\)，则：

\[
P_C=t_{CO}
\]

因此 `tvec` 的物理意义和“目标坐标系原点定义在哪里”直接相关。

## 2.2 学习中的一次理解纠正

最开始讨论“如果把目标坐标系原点从矩形中心改到左上角”时，我的理解不够精确。后来纠正为：

> `t_CO` 始终表示“当前目标坐标系原点”在相机坐标系中的位置。目标坐标系原点改变，`t_CO` 的数值通常也会改变。

如果只是平移目标坐标系原点而不改变坐标轴方向，则：

- \(R_{CO}\) 不变；
- \(t_{CO}\) 改变。

这个理解后来直接帮助理解了 `solvePnP()` 的 `tvec`。

## 2.3 建立模拟矩形三维模型

为了练习，使用模拟矩形：

\[
W=0.20\text{ m},\qquad H=0.10\text{ m}
\]

目标坐标系原点设在矩形中心，四个角点：

\[
P_1=\left(-\frac W2,-\frac H2,0\right),\quad
P_2=\left(+\frac W2,-\frac H2,0\right)
\]

\[
P_3=\left(+\frac W2,+\frac H2,0\right),\quad
P_4=\left(-\frac W2,+\frac H2,0\right)
\]

代码：

```python
object_points = np.array([
    [-width / 2, -height / 2, 0.0],
    [ width / 2, -height / 2, 0.0],
    [ width / 2,  height / 2, 0.0],
    [-width / 2,  height / 2, 0.0]
], dtype=np.float64)
```

数组形状 `(4, 3)` 表示 4 个三维点，每个点有 \(X,Y,Z\) 三个坐标。

## 2.4 为什么 \(Z_O=0\) 但 \(Z_C\) 可以约为 2 m？

当时我的理解：

> “这两个现象并不矛盾，因为是在两个不同参考系下的坐标。”

这是正确的。\(Z_O=0\) 只表示四个角点都位于目标自身平面。经过

\[
P_C=R_{CO}P_O+t_{CO}
\]

后，相机坐标系中的深度 \(Z_C\) 完全可以是 1.5 m、2 m 等正值；目标倾斜时，四个角点的 \(Z_C\) 甚至可以不同。

# 三、模块 B：PnP 数学模型

## 3.1 PnP 的定义

PnP：**Perspective-n-Point（透视 n 点位姿求解）**。

它解决：

\[
\boxed{\text{已知若干 3D 点及其对应 2D 投影} \rightarrow \text{估计相对位姿 }R,t}
\]

在本题中：

### 已知

- 目标坐标系下的三维模型点 \(P_{O,i}\)；
- 图像中的二维观测 \(p_i=(u_i,v_i)\)；
- 相机内参 \(K\)；
- 畸变参数。

### 未知

\[
R_{CO},\qquad t_{CO}
\]

即 6DoF：3 个旋转自由度 + 3 个平移自由度。

## 3.2 从 Day 1 正向投影得到 PnP 方程

三维点先变换到相机坐标系：

\[
P_{C,i}=R_{CO}P_{O,i}+t_{CO}
\]

设：

\[
P_{C,i}=\begin{bmatrix}X_{C,i}\\Y_{C,i}\\Z_{C,i}\end{bmatrix}
\]

理想针孔投影：

\[
u_i=f_x\frac{X_{C,i}}{Z_{C,i}}+c_x,
\qquad
v_i=f_y\frac{Y_{C,i}}{Z_{C,i}}+c_y
\]

齐次形式：

\[
\boxed{
s
\begin{bmatrix}u\\v\\1\end{bmatrix}
=
K
\begin{bmatrix}R&t\end{bmatrix}
\begin{bmatrix}X\\Y\\Z\\1\end{bmatrix}
}
\]

其中 \(s\) 是齐次尺度，在标准针孔模型中和相机深度有关。

## 3.3 为什么一个二维点不能直接恢复唯一三维点？

通过内参可以得到归一化方向：

\[
\begin{bmatrix}x\\y\\1\end{bmatrix}
\]

但真实三维点应写成：

\[
\boxed{P_C=\lambda\begin{bmatrix}x\\y\\1\end{bmatrix}}
\]

其中 \(\lambda\) 是未知深度尺度。

也就是说：

\[
\begin{bmatrix}x\\y\\1\end{bmatrix},
\quad
2\begin{bmatrix}x\\y\\1\end{bmatrix},
\quad
5\begin{bmatrix}x\\y\\1\end{bmatrix}
\]

都在同一条从相机光心出发的射线上，并投影到同一个二维点。

我当时的理解：

> “如果不引入深度，无法精确确定三维点的位置，因为二维位置只要是等比例向量，得到的二维点一致。”

这是正确的。

## 3.4 一个 3D–2D 对应点提供两个独立约束

由：

\[
x=\frac{X_C}{Z_C},\qquad y=\frac{Y_C}{Z_C}
\]

消掉除法：

\[
X_C-xZ_C=0
\]

\[
Y_C-yZ_C=0
\]

因此一个 3D–2D 对应点提供两个独立图像约束。

## 3.5 为什么多个点能共同约束位姿？

多个三维点不能各自任意选择深度，因为它们属于同一个刚体，并共享同一个 \(R,t\)。例如：

\[
\boxed{
\|P_{O,1}-P_{O,2}\|
=
\|P_{C,1}-P_{C,2}\|
}
\]

我的回答：

> “还需要满足距离相等约束，\(P_{O1}P_{O2}=P_{C1}P_{C2}\)。”

这是正确的核心理解。进一步说，不仅距离保持，整个刚体的相对几何结构都会保持。

## 3.6 为什么必须知道目标真实尺寸？

如果整个三维模型放大 2 倍：

\[
P'_O=2P_O
\]

同时：

\[
t'=2t
\]

则：

\[
P'_C=2P_C
\]

透视投影中：

\[
\frac{2X_C}{2Z_C}=\frac{X_C}{Z_C}
\]

二维图像不变。因此：

\[
\boxed{\text{真实模型尺度决定 }t\text{ 的真实尺度}}
\]

- `objectPoints` 用 m → `tvec` 单位为 m；
- `objectPoints` 用 mm → `tvec` 单位为 mm。

# 四、重投影误差

## 4.1 定义

PnP 得到：

\[
R_{\text{est}},t_{\text{est}}
\]

后，把同一组三维模型点再次做正向投影：

\[
P_O
\rightarrow
R_{\text{est}}P_O+t_{\text{est}}
\rightarrow
p^{pred}
\]

其中：

- \(p^{obs}\)：图像实际观测；
- \(p^{pred}\)：根据当前估计位姿重新投影出的预测像素。

重投影残差：

\[
\boxed{e=p^{obs}-p^{pred}}
\]

例如：

\[
p^{pred}=(400,250),\qquad p^{obs}=(403,246)
\]

则：

\[
e=\begin{bmatrix}3\\-4\end{bmatrix},\qquad \|e\|=5\text{ px}
\]

## 4.2 为什么叫“重投影”？

真实相机已经完成过一次三维到二维成像；得到位姿估计后，再把三维模型按估计位姿投影一次，因此叫 Reprojection（重新投影）。

## 4.3 学习中的符号问题：\(\pi\)

一开始为了简写投影过程，引入 \(\pi(P_C)\) 表示投影函数，但解释不充分，我误以为它是比例系数。

后来明确：

\[
\pi(\cdot)=\text{投影函数辅助记号}
\]

真正的尺度符号是：

\[
s,\quad \lambda
\]

这次也暴露了一个教学上的注意点：新的数学符号必须先定义输入、输出和物理含义，再用于核心公式。

## 4.4 PnP 如何得到 \(R,t\)？

我当时提出：

> “我们是怎么得到预测的 \(R,t\) 的呢？这和我们前面学的内容有什么关系？”

最终明确：

\[
\boxed{\text{3D–2D 对应} \rightarrow \text{PnP} \rightarrow R_{\text{est}},t_{\text{est}}}
\]

然后才有：

\[
\boxed{R_{\text{est}},t_{\text{est}} \rightarrow \text{正向投影} \rightarrow p^{pred}}
\]

真正被“预测”的是二维观测，而不是 \(R,t\)。

## 4.5 与 ESKF 的联系

ESKF：

\[
r=z-h(x)
\]

PnP：

\[
e=p^{obs}-p^{pred}
\]

可类比：

- \(R,t\) ↔ 待估计状态；
- \(p^{pred}\) ↔ 预测观测；
- \(p^{obs}\) ↔ 实际观测；
- \(p^{obs}-p^{pred}\) ↔ 观测残差。

但机制层级不同：ESKF 是随时间递推的状态估计器，单帧 PnP 是静态几何位姿估计问题。

## 4.6 计算误差不等于自动修正位姿

\[
\boxed{\text{计算重投影误差}\neq\text{自动修改 }R,t}
\]

重投影误差既可以作为结果验证指标，也可以在进一步非线性优化中作为目标函数修正位姿。PnP 是问题类型，P3P、DLT、EPnP、IPPE、ITERATIVE 等是不同具体算法。

# 六、模块 C：OpenCV `solvePnP()` 接口

核心接口：

```python
success, rvec, tvec = cv2.solvePnP(
    object_points,
    image_points,
    camera_matrix,
    dist_coeffs,
    flags=cv2.SOLVEPNP_IPPE
)
```

## 6.1 `objectPoints`

目标坐标系中的三维模型点，今天形状 `(4,3)`。

## 6.2 `imagePoints`

对应三维点在图像中的二维像素观测。必须严格保证：

\[
\boxed{objectPoints[i]\leftrightarrow imagePoints[i]}
\]

是同一个物理角点。

“左下、右下、右上、左上”等编号指的是目标模型中的固定物理编号，而不是简单按图像视觉位置排序。

## 6.3 `cameraMatrix`

内参矩阵：

\[
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
\]

作用是把像素坐标和相机空间观察方向联系起来。

## 6.4 `distCoeffs`

当前二维观测对应的畸变参数。今天使用常见五参数顺序：

```python
[k1, k2, p1, p2, k3]
```

重要原则：

\[
\boxed{\text{二维点所在坐标模型必须和传入的相机模型一致}}
\]

如果二维点已经去畸变，就不能再重复应用原畸变参数。

## 6.5 `flags`

今天使用：

```python
cv2.SOLVEPNP_IPPE
```

原因：四个矩形角点严格共面。

`SOLVEPNP_IPPE_SQUARE` 是专门针对正方形目标的，不适合今天的 \(0.20\text{ m}\times0.10\text{ m}\) 长方形模型。

# 七、`rvec`、`Rodrigues` 与 `tvec`

## 7.1 `rvec`

`rvec` 是 Rotation Vector（旋转向量）：

\[
\phi=\theta n
\]

其中 \(n\) 为单位旋转轴，\(\theta\) 为旋转角，\(\|\phi\|=\theta\)。它不是 Roll/Pitch/Yaw。

## 7.2 Rodrigues

```python
R, _ = cv2.Rodrigues(rvec)
```

完成：

\[
\boxed{\text{Rotation Vector}\rightarrow\text{Rotation Matrix}}
\]

从而回到：

\[
P_C=RP_O+t
\]

## 7.3 `tvec`

在当前任务中：

\[
\boxed{tvec=t_{CO}}
\]

表示 Object Frame 原点在 Camera Frame 中的位置。

如果目标坐标系原点在矩形中心：

```python
tvec = [0.2, -0.1, 1.8]^T
```

则表示矩形中心位于相机右方 0.2 m、相机视野上方 0.1 m、相机前方 1.8 m。

`tvec` 不是“相机在目标坐标系中的位置”。若要求相机原点在目标坐标系中的位置：

\[
P_{O,\text{camera}}=-R^Tt
\]

# 八、结果验证：位姿误差与重投影误差

## 8.1 平移误差

\[
e_t=t_{\text{est}}-t_{\text{gt}}
\]

总体平移误差：

\[
\boxed{\|e_t\|}
\]

## 8.2 旋转误差

不能简单使用：

```python
rvec_est - rvec_gt
```

作为严格旋转误差。

应先构造：

\[
\boxed{R_{\text{err}}=R_{\text{est}}R_{\text{gt}}^T}
\]

若估计完全正确：

\[
R_{\text{err}}=I
\]

旋转误差角：

\[
\boxed{
\theta_{\text{err}}
=
\cos^{-1}\left(\frac{\operatorname{tr}(R_{\text{err}})-1}{2}\right)
}
\]

也可理解为：

\[
\delta\theta=\operatorname{Log}(R_{\text{err}})^\vee
\]

且 \(\|\delta\theta\|=\theta_{\text{err}}\)。

## 8.3 `np.clip`

```python
cos_theta = np.clip(cos_theta, -1.0, 1.0)
```

用于避免浮点误差导致 \(\cos\theta\) 略微超出 `[-1,1]`，从而使 `np.arccos()` 产生 `nan`。这是数值安全处理，不是新的几何机制。

## 8.4 重投影 RMSE

每个点：

\[
e_i=p_i^{obs}-p_i^{pred}
\]

每个点像素误差：

\[
d_i=\|e_i\|
\]

总体 RMSE：

\[
\boxed{
\mathrm{RMSE}
=
\sqrt{\frac1N\sum_{i=1}^{N}\|e_i\|^2}
}
\]

单位为 px。

# 九、代码细节：`reshape(-1, 2)` 中的 `-1`

学习过程中专门问了：

```python
reprojected_points.reshape(-1, 2)
```

为什么有 `-1`。

结论：

\[
\boxed{-1=\text{让 NumPy 自动推断这一维}}
\]

例如原 shape 为 `(4,1,2)`，共有 8 个元素，执行 `reshape(-1,2)` 后，第二维确定为 2，第一维自动推断为 4，结果 `(4,2)`。

可理解为：

> “每个点两个坐标，点数自动推断。”

说明：

# 十三、今天最终代码

```python
import numpy as np
import cv2

# 1. 模拟相机内参
fx = 500.0
fy = 500.0
cx = 320.0
cy = 240.0

camera_matrix = np.array([
    [fx,  0.0, cx],
    [0.0, fy,  cy],
    [0.0, 0.0, 1.0]
], dtype=np.float64)

# 2. 模拟畸变参数 [k1, k2, p1, p2, k3]
dist_coeffs = np.array(
    [-0.2, 0.0, 0.01, 0.0, 0.0],
    dtype=np.float64
)

# 3. 建立矩形 3D 模型，单位 m
width = 0.20
height = 0.10

object_points = np.array([
    [-width / 2, -height / 2, 0.0],
    [ width / 2, -height / 2, 0.0],
    [ width / 2,  height / 2, 0.0],
    [-width / 2,  height / 2, 0.0]
], dtype=np.float64)

# 4. Ground Truth 位姿
rvec_gt = np.array([
    [ 0.15],
    [-0.20],
    [ 0.08]
], dtype=np.float64)

tvec_gt = np.array([
    [ 0.10],
    [-0.05],
    [ 1.50]
], dtype=np.float64)

# 5. 正向生成模拟二维角点
image_points, _ = cv2.projectPoints(
    object_points,
    rvec_gt,
    tvec_gt,
    camera_matrix,
    dist_coeffs
)

image_points = image_points.reshape(-1, 2)

# 6. 无噪声 PnP
success, rvec_est, tvec_est = cv2.solvePnP(
    object_points,
    image_points,
    camera_matrix,
    dist_coeffs,
    flags=cv2.SOLVEPNP_IPPE
)

print("solvePnP success:")
print(success)
print("\nGround Truth rvec:")
print(rvec_gt)
print("\nEstimated rvec:")
print(rvec_est)
print("\nGround Truth tvec:")
print(tvec_gt)
print("\nEstimated tvec:")
print(tvec_est)
print("\nSimulated image points:")
print(image_points)

# 7. 无噪声位姿误差
R_gt, _ = cv2.Rodrigues(rvec_gt)
R_est, _ = cv2.Rodrigues(rvec_est)

t_error = tvec_est.reshape(3) - tvec_gt.reshape(3)
translation_error = np.linalg.norm(t_error)

R_error = R_est @ R_gt.T
cos_theta = (np.trace(R_error) - 1.0) / 2.0
cos_theta = np.clip(cos_theta, -1.0, 1.0)
rotation_error_rad = np.arccos(cos_theta)
rotation_error_deg = np.degrees(rotation_error_rad)

print("\nTranslation error vector:")
print(t_error)
print("Translation error norm:")
print(translation_error, "m")
print("\nRotation error:")
print(rotation_error_deg, "deg")

# 8. 无噪声重投影误差
reprojected_points, _ = cv2.projectPoints(
    object_points,
    rvec_est,
    tvec_est,
    camera_matrix,
    dist_coeffs
)

reprojected_points = reprojected_points.reshape(-1, 2)
residuals = image_points - reprojected_points
point_errors = np.linalg.norm(residuals, axis=1)
reprojection_rmse = np.sqrt(
    np.mean(np.sum(residuals ** 2, axis=1))
)

print("\nReprojected points:")
print(reprojected_points)
print("\nReprojection residuals:")
print(residuals)
print("\nPoint reprojection errors:")
print(point_errors)
print("\nReprojection RMSE:")
print(reprojection_rmse, "px")

# 9. 实验 2：加入固定像素扰动
pixel_noise = np.array([
    [ 0.5, -0.4],
    [-0.7,  0.6],
    [ 0.4,  0.8],
    [-0.6, -0.5]
], dtype=np.float64)

noisy_image_points = image_points + pixel_noise

print("\n==============================")
print("Experiment 2: pixel noise")
print("==============================")
print("\nPixel noise:")
print(pixel_noise)
print("\nNoisy image points:")
print(noisy_image_points)

# 10. 带噪声 PnP
success_noisy, rvec_noisy, tvec_noisy = cv2.solvePnP(
    object_points,
    noisy_image_points,
    camera_matrix,
    dist_coeffs,
    flags=cv2.SOLVEPNP_IPPE
)

print("\nsolvePnP success:")
print(success_noisy)
print("\nGround Truth rvec:")
print(rvec_gt)
print("\nNoisy estimated rvec:")
print(rvec_noisy)
print("\nGround Truth tvec:")
print(tvec_gt)
print("\nNoisy estimated tvec:")
print(tvec_noisy)

# 11. 带噪声位姿误差
R_noisy, _ = cv2.Rodrigues(rvec_noisy)

t_error_noisy = (
    tvec_noisy.reshape(3)
    - tvec_gt.reshape(3)
)
translation_error_noisy = np.linalg.norm(t_error_noisy)

R_error_noisy = R_noisy @ R_gt.T
cos_theta_noisy = (
    np.trace(R_error_noisy) - 1.0
) / 2.0
cos_theta_noisy = np.clip(cos_theta_noisy, -1.0, 1.0)
rotation_error_noisy_rad = np.arccos(cos_theta_noisy)
rotation_error_noisy_deg = np.degrees(rotation_error_noisy_rad)

print("\nNoisy translation error vector:")
print(t_error_noisy)
print("Noisy translation error norm:")
print(translation_error_noisy, "m")
print("\nNoisy rotation error:")
print(rotation_error_noisy_deg, "deg")

# 12. 带噪声重投影误差
reprojected_noisy, _ = cv2.projectPoints(
    object_points,
    rvec_noisy,
    tvec_noisy,
    camera_matrix,
    dist_coeffs
)

reprojected_noisy = reprojected_noisy.reshape(-1, 2)
residuals_noisy = noisy_image_points - reprojected_noisy
point_errors_noisy = np.linalg.norm(residuals_noisy, axis=1)
reprojection_rmse_noisy = np.sqrt(
    np.mean(np.sum(residuals_noisy ** 2, axis=1))

print("\nNoisy reprojected points:")
print(reprojected_noisy)
print("\nNoisy reprojection residuals:")
print(residuals_noisy)

print(point_errors_noisy)
```

# 十七、最值得记住的几点

1. **PnP 不是一个 OpenCV 函数名，而是一类 3D–2D 位姿估计问题。**
2. **一个二维点只给一条空间射线，不能单独恢复真实深度。**
3. **多个三维模型点因为共享同一个刚体 \(R,t\)，才能共同约束位姿。**
4. **真实三维模型尺度决定 `tvec` 的尺度。**
5. **`tvec` 表示 Object Frame 原点在 Camera Frame 下的位置。**
6. **`objectPoints[i]` 与 `imagePoints[i]` 必须严格对应同一个物理点。**
7. **畸变模型必须与当前二维点所在坐标模型一致。**
8. **旋转误差要比较相对旋转，不能简单相减 `rvec`。**
9. **重投影误差衡量的是“二维解释能力”，不是三维正确性的充分证明。**
10. **今天的模拟实验已经验证：不到 1 px 的二维扰动，可以造成毫米级平移误差和数度旋转误差，而重投影误差仍然只有约 0.48 px。**
