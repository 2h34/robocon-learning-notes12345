# STM32 GPIO、定时器与外设控制基础总结

> 本文整理了当前已经学习的 STM32 基础知识，重点围绕 GPIO、输入输出模式、定时器、PWM、外设驱动与常见电气接口展开。

## 一、GPIO：STM32 与外界交流的引脚

GPIO 是可以由程序配置的通用输入输出引脚。

### 1. 输入模式

输入模式下：

> 外部电路决定引脚电压，STM32 负责读取。

典型对象包括：

- 按键
- 数字传感器
- 限位开关
- 驱动器反馈信号

例如，传感器输出 `0 V` 或 `3.3 V`，STM32 通过 GPIO 判断它是低电平还是高电平。

### 2. 输出模式

输出模式下：

> STM32 决定引脚电压，外部电路接收控制信号。

典型对象包括：

- LED
- 蜂鸣器控制端
- 电机驱动器使能端
- 片选信号
- PWM 输出

需要注意，GPIO 通常是**信号接口**，不是大功率供电接口。

---

## 二、高电平、低电平与共地

对于常见的 3.3 V STM32 系统，可以先近似理解为：

```text
接近 3.3 V → 高电平 → 逻辑 1
接近 0 V   → 低电平 → 逻辑 0
```

这里的电压都需要一个参考点，这个参考点通常是 `GND`。

因此，STM32 向驱动器发送控制信号时，通常还要连接：

```text
STM32 GND ── 驱动器信号 GND
```

这叫**共地**。

共地的目的不是让两者使用相同供电电压，而是让它们使用同一个电压参考。例如：

```text
STM32 使用 3.3 V
电机使用 24 V
但 STM32 与驱动器信号地相连
```

## 三、浮空、上拉与下拉

### 1. 浮空输入

输入引脚没有连接到明确电压时，称为浮空。

由于输入端阻抗很高，微弱干扰就可能让读取结果在 0 和 1 之间变化。因此，普通数字输入一般不能长期悬空。

### 2. 上拉输入

通过电阻让 GPIO 在无人控制时默认保持高电平：

```text
3.3 V
  │
上拉电阻
  │
GPIO
```

### 3. 下拉输入

通过电阻让 GPIO 在无人控制时默认保持低电平：

```text
GPIO
  │
下拉电阻
  │
GND
```

### 4. 按键的典型接法

按键按下时将 GPIO 接到 GND，并启用上拉：

```text
      3.3 V
        │
      上拉电阻
        │
GPIO ──┬── 按键 ── GND
```

此时：

```text
按键松开 → GPIO 读取 1
按键按下 → GPIO 读取 0
```

这种“事件发生时读取 0”的方式叫：

> **低电平有效**

程序中常见：

```c
if (key_state == 0)
{
    // 按键按下
}
```

STM32 内部通常可以直接启用内部上拉或内部下拉，不一定需要额外焊接电阻。

## 四、推挽输出与开漏输出

这是 GPIO 部分最核心的一组概念。

### 1. 推挽输出

推挽输出可以：

- 主动输出高电平
- 主动输出低电平

也就是：

```text
输出 1 → GPIO 主动接近 3.3 V
输出 0 → GPIO 主动接近 0 V
```

特点是：

- 高低电平都明确
- 切换速度较快
- 通常不需要上拉电阻
- 适合普通独立控制信号

常见场景：

- LED
- 蜂鸣器控制
- PWM
- 电机驱动器控制端
- SPI 等普通数字输出

### 2. 开漏输出

开漏输出只能：

- 主动拉低
- 或者放开线路

它不能主动输出高电平。

```text
输出 0 → 主动拉到 GND
输出 1 → 进入高阻态，放开线路
```

要得到高电平，一般需要上拉电阻：

```text
3.3 V
  │
上拉电阻
  │
信号线
```

开漏的价值在于：多个设备可以共用同一根线路，而不会发生一个设备强行输出高电平、另一个设备强行输出低电平的对抗。

因此，I²C 的 SDA 和 SCL 通常使用开漏结构。

### 3. 核心对比

| 项目 | 推挽输出 | 开漏输出 |
|---|---|---|
| 主动拉高 | 可以 | 不可以 |
| 主动拉低 | 可以 | 可以 |
| 通常需要上拉电阻 | 否 | 是 |
| 多设备共享线路 | 不适合 | 适合 |
| 常见应用 | LED、PWM、普通控制 | I²C、共享状态线 |

最简判断：

> **普通独立输出用推挽；多设备共享线路常用开漏。**

## 五、定时器与中断

### 1. 为什么使用定时器

让 LED 每隔 500 ms 切换一次，可以用延时实现：

```c
LED亮;
等待500 ms;
LED灭;
等待500 ms;
```

但这种方式可能让 CPU 在等待期间无法及时处理其他任务。

定时器是 STM32 内部专门负责计时的硬件模块。CPU 启动定时器后，可以继续：

- 读取传感器
- 处理通信
- 控制电机
- 执行控制算法

### 2. 中断

定时器到达设定时间后，可以主动通知 CPU，这种机制叫中断。

流程是：

```text
CPU 执行主程序
↓
定时器到时
↓
触发中断
↓
CPU 执行中断服务函数
↓
返回主程序
```

中断服务函数应尽量短，适合做：

```c
LED状态取反;
```

不适合放入：

- 长时间延时
- 大量复杂计算
- 很慢的通信操作

轮询和中断的区别是：

- 轮询：CPU 不断主动检查事件是否发生
- 中断：事件发生后，硬件主动通知 CPU

## 六、PWM：用快速开关实现连续控制效果

普通 GPIO 只能输出高或低，但通过高速切换，可以得到 PWM 波形：

```text
高 → 低 → 高 → 低 → ……
```

PWM 全称是脉冲宽度调制。

### 1. 周期和频率

一次完整的“高电平 + 低电平”称为一个周期。

频率表示每秒重复多少个周期：

\[
f=rac{1}{T}
\]

例如每秒重复 1000 次，就是：

\[
f=1000\ 	ext{Hz}
\]

### 2. 占空比

占空比表示一个周期中，高电平时间所占的比例：

\[
D=rac{t_{	ext{高}}}{T}
\]

例如一个周期为 10 ms，其中高电平持续 8 ms，则占空比为 80%。

在“高电平点亮 LED”的情况下：

- 占空比提高，LED 通常变亮
- 占空比降低，LED 通常变暗

但要注意，有些电路是低电平有效，此时亮暗关系可能反过来。

### 3. 频率与占空比的区别

- 频率：每秒重复多少次
- 占空比：每个周期中高电平占多少比例

控制 LED 时，占空比主要影响亮度；控制无源蜂鸣器时，频率主要影响音调。

## 七、定时器中的 PSC、ARR、CCR

可以把定时器想成一个不断数数的计数器。

### 1. PSC：预分频器

PSC 负责降低定时器的计数速度。

```text
PSC：决定计数器每一步走多快
```

常见 STM32 中实际分频数通常为：

\[
PSC+1
\]

因此，要实现 72 分频，寄存器往往填写：

```c
PSC = 71;
```

### 2. ARR：自动重装载值

ARR 决定计数器数到哪里后重新从 0 开始。

```text
ARR：决定一圈要走多少步
```

例如：

```text
ARR = 999
```

计数过程是：

```text
0 → 1 → 2 → … → 999 → 0
```

一个周期共有 1000 个计数。

### 3. CCR：比较值

CCR 决定计数到哪里时改变输出电平。

```text
CCR：决定一圈中高电平持续多少步
```

例如：

```text
ARR = 999
CCR = 500
```

在当前假定的 PWM 模式下，占空比约为 50%。

### 4. 三个核心关系

计数频率：

\[
f_{	ext{count}}
=
rac{f_{	ext{timer}}}{PSC+1}
\]

PWM 频率：

\[
f_{	ext{PWM}}
=
rac{f_{	ext{timer}}}
{(PSC+1)(ARR+1)}
\]

占空比近似为：

\[
Dpprox rac{CCR}{ARR+1}
\]

最重要的记忆方式是：

```text
PSC：走得多快
ARR：一圈多长
CCR：高电平占一圈多少
```

## 八、定时器通道与复用功能

### 1. 复用功能

一个 STM32 引脚可能同时支持：

- 普通 GPIO
- 定时器 PWM
- 串口
- SPI
- I²C

程序需要决定该引脚当前采用哪一种功能。

要让定时器产生的 PWM 从某个物理引脚输出，需要将该引脚配置成对应的**复用功能**。

例如：

```text
PA6 → TIM3_CH1
```

表示 PA6 可以作为 TIM3 第 1 通道的输出引脚。

### 2. 定时器通道

一个定时器通常有多个通道：

```text
TIM3_CH1
TIM3_CH2
TIM3_CH3
TIM3_CH4
```

同一定时器的不同通道通常共用：

- PSC
- ARR
- 计数器

所以它们通常具有相同频率。

但各通道拥有不同的 CCR，因此可以有不同占空比：

```text
CH1：20%
CH2：50%
CH3：80%
```

如果需要 20 kHz 和 50 Hz 两种明显不同的 PWM 频率，通常应使用两个不同的定时器。

## 九、GPIO 不能直接驱动大功率负载

GPIO 能够输出高低电平，但输出电流能力有限。

因此，一般不能直接连接：

- 直流电机
- 大功率蜂鸣器
- 继电器线圈
- 电磁阀
- 大功率灯具

正确结构通常是：

```text
STM32 GPIO / PWM
        ↓ 控制信号
      驱动电路
        ↓ 功率电流
       负载
```

例如控制电机：

```text
STM32 → 电机驱动器 → 电机
          ↑
       电池供电
```

STM32 负责决定：

- 启停
- 转向
- PWM 占空比
- 使能状态

驱动器和电池负责提供功率。

## 十、3.3 V 与 5 V 信号

STM32 通常使用 3.3 V 逻辑，但外部设备可能输出 5 V。

此时需要分清两个问题：

1. 逻辑上是否能识别为高电平
2. 电气上是否能安全承受 5 V

5 V 很容易被识别为高电平，但 GPIO 不一定能够承受 5 V。

因此必须检查：

- 芯片数据手册
- 引脚是否为 5 V 容忍引脚
- 当前引脚模式
- 最大输入电压

若不支持，需要采用：

- 电阻分压
- 电平转换芯片
- 三极管或 MOS 管
- 光耦等方案

核心结论：

> **能够识别，不等于能够承受。**

## 十一、有源蜂鸣器与无源蜂鸣器

### 1. 有源蜂鸣器

内部自带振荡电路，通常给一个有效电平就能响。

```text
有效电平 → 响
无效电平 → 不响
```

它主要用于简单提示音。

### 2. 无源蜂鸣器

内部没有振荡电路，需要外部提供周期信号。

通常使用 PWM 控制：

- 改变频率，改变音调
- 控制信号启停，决定是否发声

因此，需要播放不同音高时，更适合使用无源蜂鸣器。

---

## 十二、三极管或 MOS 管作为电子开关

GPIO 不能直接提供较大负载电流时，可以用三极管或 MOS 管控制负载。

```text
GPIO
  ↓ 控制
三极管 / MOS 管
  ↓ 开关功率回路
蜂鸣器、电机或继电器
```

此时 GPIO 的作用是：

> 控制开关导通或截止，而不是提供负载的全部功率。

当前接触到的电路结构是：

```text
电源 → 负载 → 三极管 → GND
```

三极管位于负载靠近 GND 的一侧，这叫：

> **低端开关**

这一部分刚刚开始，后续可以继续学习低端开关和高端开关的区别。

## 十三、实际场景快速判断

| 实际需求 | 典型选择 |
|---|---|
| 读取传感器数字状态 | GPIO 输入 |
| 按键按下接 GND | 输入上拉 |
| 单独控制 LED | 推挽输出 |
| I²C 通信 | 开漏输出加上拉 |
| LED 调光 | 定时器 PWM |
| 无源蜂鸣器变调 | 改变 PWM 频率 |
| 多路同频不同亮度 | 同一定时器不同通道 |
| 两路明显不同频率 | 不同定时器 |
| 控制电机 | GPIO / PWM 接驱动器 |
| 5 V 信号接 STM32 | 先查 5 V 容忍能力 |
| 较大电流负载 | 三极管、MOS 管或专用驱动器 |
