## 1. 任务目标与最终方案

题目二要求基于 IMU 与 FAST-LIO 姿态数据实现 EKF/ESKF 姿态解算，并输出 Roll / Pitch / Yaw 及时间曲线。

最终采用：

### Nominal State（名义状态）

\[
\hat{x}=(\hat q,\hat b_g)
\]

其中：

- \(\hat q\)：姿态四元数；
- \(\hat b_g\)：陀螺仪零偏估计。

### Error State（误差状态）

\[
\delta x=
\begin{bmatrix}

# 2. Day1：姿态表示

## 2.1 Rotation Matrix（旋转矩阵）

\[
R\in SO(3)
\]

本项目固定：

\[
R_{WB}
\]

表示 Body Frame → World Frame：

\[
v_W=R_{WB}v_B
\]

这个 convention 决定了后续四元数方向、IMU 增量乘法方向、FAST-LIO Observation 方向和 residual 的构造。

## 2.2 Rotation Vector（旋转向量）

\[
\phi=\theta n
\]

方向是旋转轴，模长是旋转角。

后续工程中最重要的两类旋转向量：

\[
\Delta\theta_{imu}
\]

表示 IMU 推算的名义旋转增量，即“这一帧转了多少”；

\[
\delta\theta
\]

表示 ESKF 姿态误差，即“当前姿态估计错了多少”。

必须牢记：

\[
\boxed{\Delta\theta_{imu}\neq\delta\theta}
\]

## 2.3 Quaternion（四元数）

内部姿态采用：

\[
q=[q_x,q_y,q_z,q_w]
\]

即 `xyzw`、`w` 在最后。

选择四元数是因为欧拉角存在奇异性，而四元数适合连续姿态传播和旋转复合。

工程策略：

```text
内部姿态：Quaternion
最终输出：Roll / Pitch / Yaw
```

## 2.4 RPY

最终采用 ZYX yaw-pitch-roll 约定：

\[
R=R_z(yaw)R_y(pitch)R_x(roll)
\]

RPY 只用于最终展示和人工理解，不参与滤波内部姿态传播。

# 3. Day2：SO(3)、so(3)、Exp / Log

## 3.1 SO(3) 与 so(3)

最初疑惑：

- `so(3)` 是三维向量还是 3×3 反对称矩阵？
- `so(3)` 是否就是 Rotation Vector？

最终理解：

- \(SO(3)\)：所有三维旋转矩阵构成的李群；
- \(so(3)\)：其李代数，严格来说元素是 3×3 反对称矩阵；
- 三维向量 \(\phi\) 通过 Hat Operator 映射为 \(\phi^\wedge\in so(3)\)。

所以旋转向量与 `so(3)` 元素可以通过 hat / vee 对应，但不是同一个数学对象。

## 3.2 Exp

\[
Exp:so(3)\rightarrow SO(3)
\]

作用：把局部小旋转变成真正旋转。

代码中 `rotvec_to_quaternion()` 就承担这个作用。

## 3.3 Log

\[
Log:SO(3)\rightarrow so(3)
\]

作用：把两个姿态之间的相对旋转重新变成三维小旋转。

代码中 `quaternion_to_rotvec()` 承担这个作用。

## 3.4 在 ESKF 中的位置

Prediction：

```text
ω
→ ×dt
→ Rotation Vector
→ Exp
→ Quaternion Increment
→ 更新姿态
```

Observation：

```text
q_pred 与 q_obs
→ 相对四元数
→ Log
→ 三维 residual
```

核心理解：

\[
\boxed{Exp / Log 是局部三维误差与真实旋转之间的桥}
\]

# 4. IMU 姿态传播

陀螺仪测量模型：

\[
\omega_m=\omega_{true}+b_g+n_g
\]

程序不知道真实 \(b_g\)，只有估计 \(\hat b_g\)，因此：

\[
\hat\omega=\omega_m-\hat b_g
\]

随后：

\[
\Delta\theta_{imu}=\hat\omega\Delta t
\]

再通过：

\[
\Delta q=Exp(\Delta\theta_{imu})
\]

更新：

\[
\hat q_{k+1}=\hat q_k\otimes\Delta q
\]

### 为什么右乘？

因为姿态定义为 \(R_{WB}\)，而 IMU 角速度表达在 Body Frame，所以：

\[
R_{WB}^{new}=R_{WB}^{old}\Delta R_B
\]

对应四元数右乘。

注意：这个右乘首先来自姿态方向与角速度坐标系，不是单纯因为 ESKF 使用右乘误差。

# 5. Day3：P、Q、R 与 Kalman Filter

## 5.1 P

\[
P=E[\delta x\delta x^T]
\]

表示 error state 的协方差，也就是“当前估计有多不确定”。

6D ESKF 中：

\[
P=
\begin{bmatrix}
P_{\theta\theta}&P_{\theta b}\\
P_{b\theta}&P_{bb}
\end{bmatrix}
\]

包含姿态误差、bias 误差及二者相关性。

## 5.2 Q

Prediction：

\[
P^-=\Phi P\Phi^T+Q_d
\]

其中：

- \(\Phi P\Phi^T\)：旧不确定性的传播；
- \(Q_d\)：当前 Prediction 新增的过程噪声不确定性。

## 5.3 R

FAST-LIO 也不是绝对真值，因此需要 Observation Noise Covariance：

\[
R
\]

当前按题目要求使用：

\[
R=diag(cov_{33},cov_{44},cov_{55})
\]

严格来说题面给的是 RPY covariance，而 ESKF residual 在 rotation-vector tangent space；当前作业采用小角度近似。

## 5.4 K

\[
K=P^-H^T(HP^-H^T+R)^{-1}
\]

一维直觉：

- P 大、R 小：更依赖 Observation；
- P 小、R 大：更依赖 Prediction。

后续进一步明确：K 是矩阵，不能简单理解成“整个 K 越大就越相信观测”。

# 6. EKF 到 ESKF

普通 EKF 使用非线性：

\[
x_{k+1}=f(x_k,u_k),\quad z_k=h(x_k)
\]

并用 Jacobian：

\[
F=\frac{\partial f}{\partial x},\quad
H=\frac{\partial h}{\partial x}
\]

最终形成的重要理解：

\[
\boxed{f/h 描述状态传播和观测}
\]

\[
\boxed{F/H 描述误差与不确定性传播}
\]

姿态不能直接做普通向量加法，四元数必须满足单位约束，因此 ESKF 分离：

```text
Nominal State：保存真实姿态估计
Error State：在局部三维空间估计小误差
Kalman：估计 error state
Injection：把 error state 修回 nominal state
```

---

# 7. Day4：6D ESKF 完整数学模型

连续误差动力学：

\[
\delta\dot\theta
=
-[\hat\omega]_\times\delta\theta
-\delta b_g
-n_g
\]

\[
\delta\dot b_g=n_{bg}
\]

因此：

\[
F_c=
\begin{bmatrix}
-[\hat\omega]_\times&-I\\
0&0
\end{bmatrix}
\]

\[
G_c=
\begin{bmatrix}
-I&0\\
0&I
\end{bmatrix}
\]

### Fc 四个 block

- 左上：当前旋转下姿态误差自身的变化；
- 右上：gyro bias error 会驱动态度误差；
- 左下：当前模型中姿态误差不直接驱动 bias；
- 右下：bias 没有确定性动态，随机变化由 random walk noise 表示。

## 7.1 离散化

精确：

\[
\Phi=e^{F_c\Delta t}
\]

当前工程：

\[
\Phi\approx I+F_c\Delta t
\]

连续过程噪声：

\[
Q_c
\]

当前一阶离散近似：

\[
Q_d\approx G_cQ_cG_c^T\Delta t
\]

注意：这不是任意 \(dt\) 下的精确公式。

最终：

\[
P^-=\Phi P\Phi^T+Q_d
\]

# 8. Observation Update

## 8.1 Quaternion sign alignment

四元数 \(q\) 和 \(-q\) 表示同一个姿态。

程序先让 Observation 与 Prediction 采用连续一致的代表元，避免符号跳变进入 residual。

## 8.2 Relative rotation

\[
q_{rel}=q_{pred}^{-1}\otimes q_{obs}
\]

表示从 Prediction 到 Observation 的相对旋转。

## 8.3 Residual

\[
r_\theta=Log(q_{rel})
\]

得到三维 rotation-vector residual。

## 8.4 H

\[
H=[I\quad0]
\]

FAST-LIO 直接观测姿态误差，不直接观测 bias。

但 bias 仍可通过 \(P_{\theta b}\) 的 cross-covariance 被间接修正。

## 8.5 S 与 K

\[
S=HP^-H^T+R
\]

\[
K=P^-H^TS^{-1}
\]

代码使用 `np.linalg.solve()`，避免显式求逆。

## 8.6 Error Update

\[
\delta\hat x=Kr
\]

拆成：

\[
\delta\hat x=
\begin{bmatrix}
\delta\hat\theta\\
\delta\hat b_g
\end{bmatrix}
\]

前 3 维修正 attitude，后 3 维修正 gyro bias。

# 9. Joseph Update、Injection 与 Reset

## 9.1 Covariance Update

采用 Joseph Form：

\[
P_{upd}
=
(I-KH)P^-(I-KH)^T+KRK^T
\]

它更新的是 uncertainty，不是 nominal state。

## 9.2 Injection

\[
\hat q\leftarrow
\hat q\otimes Exp(\delta\hat\theta)
\]

\[
\hat b_g\leftarrow
\hat b_g+\delta\hat b_g
\]

## 9.3 Reset

Injection 后 error-state mean 回到 0 附近，但 P 不能清零。

因为只是误差坐标原点改变：

\[
P\leftarrow
G_{reset}PG_{reset}^T
\]

当前：

\[
G_{reset,\theta}
\approx
I-\frac12[\delta\hat\theta]_\times
\]

最重要的理解：

\[
\boxed{Reset 不是把 P 清零，而是更换误差坐标}
\]

# 10. Initialization

数据开头约 2 s 静止。

静止时：

\[
\omega_{true}\approx0
\]

所以初始 gyro bias：

\[
\hat b_{g0}=mean(\omega_m)
\]

静止区间：

```text
[0, 396)
```

因此：

\[
k_0=395
\]

因为 Python 切片右开，`static_end_idx - 1` 才是最后一个静止样本。

初始姿态 \(q_0\) 来自 k0 对齐的 FAST-LIO quaternion。

P0：

\[
P_0=
diag(P_{\theta0},P_{bg0})
\]

其中 bias covariance 使用静止均值估计的不确定性。

关键理解：

\[
\delta x_0=0
\]

不代表：

\[
P_0=0
\]

error mean 为 0 与“完全无 uncertainty”是两回事。

# 12. Runner：正确算法也需要正确调度

最终调度：

```text
initial posterior at k0
↓
gyro[k] + dt[k+1]
↓
Prediction to k+1
↓
pose_index_for_imu[k+1]
↓
optional Update
↓
posterior at timestamp[k+1]
```

为什么使用 `gyro[k]` 和 `dt[k+1]`？

因为：

\[
dt[k+1]=t_{k+1}-t_k
\]

left-endpoint ZOH 用 `gyro[k]` 代表区间 \([t_k,t_{k+1}]\)。

初始化时已经使用过 k0 的 FAST-LIO Observation，所以后续不能重复 Update。

# 13. Left-endpoint ZOH 与动态 residual

正式程序采用：

\[
\Delta\theta_{imu}=\omega[k]\Delta t
\]

即 Zero-Order Hold（零阶保持）。

离线比较：

### Left endpoint

\[
\phi_{left}=\omega_k\Delta t
\]

### Trapezoid

\[
\phi_{trap}
=
\frac12(\omega_k+\omega_{k+1})\Delta t
\]

结果显示 trapezoid 对典型动态区间有明显改善。

最终结论：

\[
\boxed{ZOH 是动态 residual 的一个贡献因素，但不是唯一根因}
\]

因此本次作业保持正式模型不变，不再升级 Prediction。

# 15. Residual 与 NIS

Residual：

\[
r_\theta
\]

表示 Prediction 与 FAST-LIO Observation 的姿态差。

它不是独立真实姿态误差。

NIS：

\[
NIS=r^TS^{-1}r
\]

表示 residual 相对于 innovation uncertainty 的归一化大小。

当前只用于 diagnostic，不用于 gating、Observation rejection 或自动调参。

FAST-LIO 本身也使用 IMU，因此它只能称 Observation Reference，不能称 Independent Ground Truth。

# 20. 学习过程中最重要的认知修正

## 20.1 Rotation Vector 与 so(3)

最初容易混为一谈。

最终：

- Rotation Vector 是三维向量；
- hat 后的反对称矩阵属于 so(3)。

## 20.2 Fc 与 Phi

最终：

```text
Fc
= 连续时间误差变化率模型

Phi
= 离散相邻时刻误差传播矩阵
```

## 20.3 Δθimu 与 δθ

最终：

```text
Δθimu
= 机器人这一帧转了多少

δθ
= 当前姿态估计错了多少
```

## 20.4 Reset

最终：

```text
Error mean reset to zero
≠
P reset to zero
```

P 需要换误差坐标，而不是清空。

## 20.5 FAST-LIO 不是 Ground Truth

曲线接近只能说明 Observation consistency 较好，不能直接声称真实姿态误差很小。

## 20.6 High NIS 不等于算法必然错误

可能来源包括：

- dynamic model approximation；
- ZOH；
- covariance model；
- FAST-LIO / IMU correlation；
- timing；
- 未建模动态。

应通过诊断逐层排查，而不是先调 Q/R。

# 23. 最终总结

这次题目二真正掌握的不是一个 ESKF 脚本，而是一套完整机器人状态估计方法：

```text
Sensor
→ Coordinate / State Representation
→ Motion Model
→ Prediction
→ Uncertainty Propagation
→ Observation
→ Residual
→ Kalman Fusion
→ Injection / Reset
→ Validation
→ Engineering Delivery
```

最值得长期记住的一句话：

\[
\boxed{
ESKF 的核心不是“多一个 Kalman 公式”，而是把非线性名义状态和局部线性误差分开处理。
}
\]

即：

```text
Nominal State
负责描述“机器人现在是什么状态”

Error State
负责描述“当前估计可能错多少”

Kalman Filter
负责估计这个误差

Injection
把误差修正回 Nominal State
```

这套 6D 工程已经可以作为后续 15D ESKF、VIO、FAST-LIO、LIO-SAM 与 SLAM 状态估计学习的基础。
