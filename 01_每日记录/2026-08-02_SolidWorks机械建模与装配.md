### 3.3 轮毂STEP模型抄画

参考模型是STEP格式，导入后只有实体，没有原始草图和特征树，因此需要先分析结构，再手动重建。

本次采用的基本思路：

```text
观察整体结构
→ 找到中心轴与回转对称结构
→ 通过剖视和测量提取尺寸
→ 绘制轴向截面
→ 使用旋转成型建立主体
→ 添加局部凸台、切除和倒角
```

实际完成内容：

- 判断轮毂属于以中心轴为基准的回转类零件；
- 使用旋转特征建立基本主体；
- 在外部圆面所在基准面处绘制草图进行特征成型
- 通过“合并结果”将新凸台与原实体合并；
- 理解实体数量与合并状态之间的关系。

本次形成的核心认识：

> 复杂零件不能直接照着外形逐条描边，而应拆分为“主体、局部凸台、局部切除、重复结构和细节特征”。

### 3.4 爪子装配

完成了给定零件的导入和装配。

主要操作包括：

- 新建装配体；
- 一次选择并插入多个零件；
- 固定基座零件；
- 使用同心配合将轴类结构装入孔中；
- 使用重合配合确定零件轴向位置；
- 调整零件的固定与浮动状态；
- 将重复结构装入其他相同孔位。

本次接触的重复装配方法：

#### 普通零部件阵列

适用于零件沿直线或圆周规则分布的情况。

```text
线性零部件阵列
圆周零部件阵列
```

#### 阵列驱动的零部件阵列

适用于基座零件中已经存在孔阵列、线性阵列或圆周阵列特征的情况。

特点：

- 数量和位置由原零件中的阵列特征控制；
- 原孔阵列发生变化时，装配中的零件阵列可同步更新。

#### 随配合复制

适用于将同一零件或同一组零件重复安装到多个相似孔位。

本次爪子装配中，重复的红白结构安装到相同孔位时，使用“随配合复制”比逐个插入和重新配合更方便。

## 4. 核心概念

### 草图

- 是什么：二维轮廓和尺寸约束的集合。
- 主要作用：为拉伸、旋转、切除等三维特征提供基础。
- 注意事项：尽量使草图完全定义，避免依靠目测位置。

### 特征

- 是什么：基于草图或已有实体生成的三维操作。
- 常见特征：拉伸、切除、旋转、阵列、镜像、圆角、倒角。
- 建模原则：主体优先，细节靠后。

### 旋转成型

- 适用对象：轮毂、轴、套筒、圆柱基座等回转类零件。
- 基本方法：绘制轴向半剖面和中心线，再绕中心线旋转。
- 优点：能用一张草图建立多个同轴台阶。


### 合并结果

- 是什么：将新生成的凸台和原实体合并为同一个实体。
- 成功标志：设计树中仍显示`实体(1)`。
- 常见失败原因：
  - 未勾选“合并结果”；
  - 新特征与原实体没有实际体积交叠；
  - 拉伸方向错误；
  - 形成零厚度几何。

### 配合

- 是什么：装配体中约束零件相对位置和运动关系的方法。
- 常用类型：
  - 同心；
  - 重合；
  - 平行；
  - 垂直；
  - 距离；
  - 角度。
- 关键理解：装配的目标不是把零件拖到大致位置，而是通过配合消除不需要的自由度。

### 阵列与随配合复制

| 方法 | 适用场景 |
|---|---|
| 线性零部件阵列 | 沿直线等距重复 |
| 圆周零部件阵列 | 绕轴等角度重复 |
| 阵列驱动 | 基座已有阵列特征 |
| 随配合复制 | 相同零件装入多个相似孔位 |
| Ctrl拖动复制 | 临时快速复制零件 |

## 7. 效率提升复盘

今天主要使用了基础操作，任务已经完成，但仍有较大的效率提升空间。

### 7.1 建模前先分析结构

以后面对零件时，先判断：

1. 主体适合拉伸还是旋转；
2. 是否存在左右对称；
3. 是否存在圆周或线性重复；
4. 哪些是主要结构，哪些只是圆角、倒角等细节。

推荐顺序：

```text
观察与测量
→ 规划特征树
→ 建立主体
→ 添加主要切除和凸台
→ 使用阵列或镜像
→ 最后添加圆角和倒角
```

### 7.2 用阵列和镜像代替重复绘制

对于相同结构：

```text
只绘制一个种子特征
→ 检查尺寸和位置
→ 使用线性阵列、圆周阵列或镜像复制
```

不应手动画出所有重复孔、凸块或开窗。

### 7.3 装配时先固定基座

推荐装配顺序：

```text
固定基座
→ 安装与基座直接连接的零件
→ 逐层向外装配
→ 最后处理重复零件
```

这样可以减少零件漂移和配合混乱。

### 7.4 根据场景选择重复装配方法

- 规则圆周分布：圆周零部件阵列；
- 规则直线分布：线性零部件阵列；
- 基座本身已有阵列：阵列驱动；
- 多个相似孔位：随配合复制；
- 由多个零件组成的重复模块：先建立子装配体，再复制子装配体。

### 7.5 设置常用快捷操作

后续可优先设置以下鼠标笔势或快捷键：

```text
草图
正视于
智能尺寸
凸台拉伸
拉伸切除
旋转
测量
配合
```

先形成少量高频操作的肌肉记忆，再逐步扩展。

### 7.6 圆角和倒角尽量放在最后

原因：

- 前序特征修改后，边线编号可能变化；
- 圆角和倒角容易因引用边丢失而报错；
- 将其放在设计树末尾更容易修改和排错。
