## 3. 今日完成内容

### 3.1 硬件组职责与工作流程

硬件组的工作主要分为两部分：

#### 嵌入式硬件系统设计

根据机器人功能需求，完成从需求分析到电路板测试的完整流程：

```text
需求分析
→ 原理图设计
→ 元器件选型
→ PCB 布局布线
→ 焊接
→ 测试
```

#### 机器人线路布设

负责电池、控制板、电机、电磁阀、传感器和通信设备之间的电源与信号连接。

硬件组的核心任务可以概括为：

- 电源分配；
- 信号连接；
- 功率驱动；
- 电路保护；
- 故障排查。

机器人中的基本电气控制链为：

```text
传感器
→ MCU
→ 驱动电路
→ 执行器
```

重要认识：

> MCU 输出的通常只是低功率控制信号，电机、电磁阀等负载需要由驱动器、三极管或 MOS 管提供实际功率。

### 3.2 PCB 的作用与基本结构

PCB（Printed Circuit Board）是电子元器件的机械支撑体和电气连接载体。

PCB 的主要作用包括：

1. 固定电阻、电容、芯片和连接器等元器件；
2. 使用铜箔走线代替大量零散导线；
3. 提高电路的稳定性、紧凑性和可维护性。

PCB 的基本层结构如下：

| 层级 | 主要作用 |
|---|---|
| 基板 | 提供机械强度和电气绝缘 |
| 铜箔层 | 形成走线、焊盘和铺铜，传输电源与信号 |
| 阻焊层 | 防止短路和铜箔氧化，限制焊锡流动 |
| 丝印层 | 标注元器件编号、方向、接口和测试点 |

常见 PCB 颜色主要来自阻焊层，R1、C1、GND 等文字通常位于丝印层。

双层板与四层板中的“层数”，主要指导电铜箔层的数量，而不是 PCB 的全部物理材料层数。

### 3.3 电阻

电阻是最基础的无源器件之一，遵循欧姆定律：

$$
U=IR
$$

常见类型：

| 类型 | 特点 |
|---|---|
| 贴片电阻 | 常见封装有 0402、0603、0805，体积小，PCB 中最常用 |
| 插件电阻 | 体积较大，便于手工焊接，部分型号可承受较大功率 |

主要用途：

- 限流；
- 分压；
- 上拉和下拉；
- 电流采样；
- 阻抗匹配。

输入引脚悬空时容易受到噪声干扰，因此需要使用上拉或下拉电阻，使其保持确定的默认电平。

电阻的功率关系为：

$$
P=UI=I^2R=\frac{U^2}{R}
$$

因此，电阻选型不仅要考虑阻值，还要考虑额定功率。

### 3.4 电容

电容用于储存和释放电荷，其基本关系为：

$$
Q=CU
$$

电容的主要特点是：

```text
通交流、阻直流
通高频、阻低频
两端电压不能突变
```

常见类型：

| 类型 | 特点 |
|---|---|
| 贴片陶瓷电容 | 体积小、ESR 低、高频性能好 |
| 铝电解电容 | 有极性、容量大，适合电源滤波 |
| 钽电容 | 单位体积容量大、稳定性较高，但抗过压能力较弱 |

主要用途：

- 去耦与旁路；
- 电源滤波；
- 信号耦合；
- RC 定时与振荡。

去耦电容应尽量靠近芯片电源引脚，以缩短供电回路，减小寄生电阻和寄生电感，使电容能够快速补充瞬态电流并抑制高频噪声。

### 3.5 电感、磁珠与共模电感

电感能够将电能转化为磁能储存，主要特点为：

```text
通直流、阻交流
通低频、阻高频
电流不能突变
```

三类器件的主要区别：

| 类型 | 主要作用 |
|---|---|
| 功率电感 | 在 DC-DC 电路中储存和传递能量 |
| 磁珠 | 衰减电源线或信号线上的高频噪声 |
| 共模电感 | 抑制成对线路中的共模干扰 |

功率电感需要关注电感量、额定电流、饱和电流、直流电阻和封装尺寸。若进入饱和，可能导致发热、电流失控或电源异常。

### 3.6 二极管

二极管具有单向导电特性，常规电流主要从阳极 A 流向阴极 K。

| 类型 | 主要作用 |
|---|---|
| 稳压二极管 | 稳压、限幅和简单过压保护 |
| 肖特基二极管 | 低压降整流和续流 |
| TVS 管 | 吸收静电和浪涌尖峰 |
| LED | 状态指示和照明 |

感性负载如电磁阀、继电器和电机线圈断电时，会产生较高反向电压。因此通常在线圈两端并联续流二极管，为电流提供释放路径，保护 MOS 管等开关器件。

### 3.7 三极管与 MOS 管

三极管是电流控制型器件，MOS 管是电压控制型器件。

- NPN 三极管和 NMOS 常用于低端驱动；
- PNP 三极管和 PMOS 常用于高端驱动；
- 功率 MOS 适合电机、电磁阀、加热丝和开关电源等大电流场合。

典型电磁阀控制链为：

```text
STM32 GPIO
→ MOS 管栅极
→ MOS 管控制负载电流
→ 电磁阀动作
```

GPIO 不能直接驱动 24 V 电磁阀，原因包括：

- GPIO 电压通常只有 3.3 V；
- GPIO 输出电流有限；
- 电磁阀属于感性负载，断电时会产生反向冲击。


### 3.8 MCU、接口芯片、ADC 与电源管理芯片

#### MCU

MCU 集成 CPU、RAM、Flash、GPIO 和各种通信接口，是机器人控制系统的核心。

```text
接收外界信号
→ 运行程序
→ 输出控制指令
```

队内主要使用 STM32F405RGT6、STM32H723ZET6 等型号。

#### 接口芯片

接口芯片用于：

- 协议转换；
- 电平转换；
- 提高通信距离；
- 增强抗干扰能力；
- 实现高低压电气隔离。

常见器件包括 USB 转串口芯片、CAN 收发器、RS485 收发器、光耦和数字隔离器。

#### ADC

ADC 将温度、压力、电压和电流等连续模拟信号转换为数字信号。

```text
电池电压
→ 电阻分压
→ ADC
→ MCU 读取数字量
```

#### 电源管理芯片

| 类型 | 特点 |
|---|---|
| LDO | 电路简单、噪声小，适合小电流 |
| DC-DC | 转换效率高，适合大电流升降压 |
| 充电管理芯片 | 负责恒流、恒压和过充保护 |

24 V 电池不能直接给 STM32 供电，通常需要经过：

```text
24 V
→ DC-DC 降压
→ 5 V 或 3.3 V
```

### 3.9 晶振、连接器、保险丝、按键与蜂鸣器

#### 晶振

晶振为 MCU 提供稳定时钟信号。布局时应靠近 MCU、缩短走线、减少过孔和分支，并远离电机与开关电源等干扰源。

#### 连接器

连接器负责 PCB 与外部设备之间的可拆卸连接。选型时需要考虑额定电流、插接方向、机械强度、防反接和维护便利性。

#### 保险丝

保险丝用于过流保护。

- 一次性保险丝：熔断后需更换；
- 自恢复保险丝：故障消除后可恢复导通。

#### 按键与开关

常用于复位、模式选择、设备编号设置和人机交互。

#### 蜂鸣器

- 有源蜂鸣器：通电即可发声；
- 无源蜂鸣器：需要方波或 PWM 驱动。

若蜂鸣器电流超过 GPIO 输出能力，应使用三极管或 MOS 管驱动。

### 3.10 从原理图到 PCB 的基本流程

完整流程如下：

```text
需求分析
→ 绘制原理图
→ 元器件选型
→ 分配封装
→ 设置板框
→ 元器件布局
→ PCB 布线
→ GND 铺铜
→ DRC 检查
→ 导出 Gerber
→ 打板
→ 焊接与测试
```

原理图表达的是“元器件之间如何连接”，PCB 表达的是“元器件放在哪里、铜线如何走”。

即使原理图正确，PCB 仍可能因以下问题无法工作：

- 封装或引脚编号错误；
- 元器件极性装反；
- 漏连、短路或线宽不足；
- 布局不合理；
- 虚焊、连锡或元器件损坏。

### 3.11 PCB 布局与布线规则

PCB 布线需要重点关注最小间距、线宽、线长、弯折方式、走线优先级和差分线等长。

#### 最小间距

不同网络之间需要保持足够距离，避免短路、焊接连锡和信号干扰。

#### 线宽

走线越宽，通常能够承载的电流越大。电机、电磁阀等大电流线路应明显宽于普通 GPIO 信号线，否则可能出现压降、发热、供电不稳定或走线烧毁。

#### 线长

晶振、时钟、通信和模拟采样信号应尽量缩短，以减少延迟、衰减和干扰。

#### 弯折方式

应减少不必要的弯折，避免锐角，优先使用直线、圆弧或平缓折线。

#### CAN 差分线

CAN_H 和 CAN_L 应尽量：

- 并行；
- 等长；
- 间距稳定；
- 少分支；
- 少绕行。

### 3.12 铺铜、板层与 DRC

#### GND 铺铜

GND 铺铜的主要作用：

- 降低地线阻抗；
- 改善电流回流路径；
- 提高抗干扰能力；
- 增强大电流承载能力。

铺铜后需要检查是否连接到正确网络、是否存在孤立铜皮、是否满足间距规则，以及修改布线后是否重新更新铺铜。

#### 常见板层

| 图层 | 主要内容 |
|---|---|
| 顶层 | 正面走线、焊盘和铺铜 |
| 底层 | 背面走线、焊盘和铺铜 |
| 顶层丝印 | 正面文字与器件标识 |
| 底层丝印 | 背面文字与器件标识 |
| 阻焊层 | 决定铜面开窗位置 |
| 板框层 | 定义 PCB 外形和尺寸 |

#### 过孔

过孔用于连接不同铜层。大电流网络需要使用更大或多个并联过孔，普通信号也不应无意义地频繁换层。

#### DRC

DRC 可检查：

- 短路；
- 未连接网络；
- 间距不足；
- 线宽违规；
- 铜箔与板框冲突；
- 过孔和焊盘规则错误。

但 DRC 不能完全检查元器件极性、引脚定义、功能逻辑、封装尺寸、接口线序和布局合理性，因此 DRC 通过后仍需人工核对。

### 3.13 嘉立创打板与电池安全

#### 嘉立创打板流程

```text
注册账号
→ 领取免费打样券
→ 完成 PCB 设计
→ DRC 检查
→ 导出或提交生产文件
→ 设置板材、层数、板厚、铜厚和阻焊颜色
→ 提交订单
```

#### 6S 航模锂电池

队内使用 6S 24 V 航模锂电池。

单节电芯满电电压约为：

$$
4.2\ \text{V}
$$

整组满电电压约为：

$$
6\times4.2=25.2\ \text{V}
$$

当整体电压低于约 22.8 V 时，应立即停止使用并充电。

BB 响连接到平衡接口，可检测各节电芯电压，在某节电芯电压过低时报警。

安全要求：

- 使用平衡充电器；
- 严禁过放；
- 远离易燃物；
- 不短接正负极；
- 电池鼓包后立即停用；
- 使用后放入防爆柜；
- 检查电源线和平衡线是否破损。

### 3.14 焊接、绝缘处理与万用表

#### 焊接工具

- 剥线钳；
- 焊刀；
- 锡丝；
- 助焊剂；
- 热缩管；
- 电工胶带。

#### 基本焊接流程

```text
剥线
→ 提前套热缩管
→ 两端上锡
→ 固定
→ 补锡
→ 检查
→ 绝缘处理
```

焊刀温度一般控制在约：

$$
350^\circ\text{C}
$$

合格焊点应光亮、饱满、牢固，无虚焊和尖刺。

#### 万用表常用档位

| 档位 | 主要用途 |
|---|---|
| 电阻档 | 测量元器件或线路电阻 |
| 蜂鸣档 | 快速判断线路是否导通 |
| 直流电压档 | 测量电池、电源和芯片供电电压 |

焊接完成后，应先在断电状态下使用蜂鸣档检查导通与短路，再上电测量关键电压。

## 4. 核心概念

### PCB

- 是什么：电子元器件的支撑体和电气连接载体；
- 基本结构：基板、铜箔层、阻焊层和丝印层。

### 控制信号与功率输出

```text
MCU GPIO
→ 三极管、MOS 管或驱动芯片
→ 大功率负载
```

GPIO 负责控制，不负责直接提供负载功率。

### 去耦电容

- 为芯片瞬态抽电提供本地储能；
- 抑制高频噪声；
- 应靠近芯片电源引脚。

### 功率电感与磁珠

- 功率电感：用于储能和电源转换；
- 磁珠：用于抑制高频噪声；
- 二者不能简单互换。

### 续流二极管

- 用于电磁阀、继电器和电机线圈；
- 为断电后的电流提供释放路径；
- 保护 MOS 管等开关器件。

### MCU、接口、ADC 与电源管理

```text
MCU：负责控制
接口芯片：负责通信与转换
ADC：负责采集模拟量
电源管理芯片：负责供电
```

### PCB 布线

- 大电流线路加宽；
- 关键高频信号缩短；
- CAN 差分线并行、等长；
- 避免锐角和复杂绕行；
- 先合理布局，再完成布线。

### DRC 与人工检查

- DRC 检查规则违规；
- 人工核对功能、封装、方向、接口和布局；
- DRC 通过不代表电路功能一定正确。

### 6S 电池

- 满电约 25.2 V；
- 低于约 22.8 V 时停止使用；
- 使用平衡充电器；
- 严禁过放和短路。

### 万用表

- 蜂鸣档：查导通；
- 电阻档：测阻值；
- 直流电压档：测供电电压；
- 电阻档和蜂鸣档通常应在断电状态下使用。

| 误以为 DRC 通过即可直接生产 | DRC 只检查规则，不检查全部功能 | 增加人工核对原理图、封装、极性和接口线序 | 已解决 |
| 对大电流线为何加宽理解较简单 | 只知道电流更大 | 补充电阻、压降、发热和烧线风险 | 已基本理解 |
| 对电池过放的风险认识不足 | 只关注机器人能否继续运动 | 明确低压阈值、BB 响和平衡充电作用 | 已解决 |
| 不熟悉焊接后如何检查 | 缺少标准检查流程 | 建立“外观—蜂鸣—短路—电压—功能”检查顺序 | 已解决 |

## 7. 效率提升复盘

### 7.1 学习元器件时按“特性—用途—位置”分析

推荐分析框架：

```text
它的基本物理特性是什么
→ 它在电路中承担什么功能
→ 它为什么放在这个位置
→ 选型时需要检查哪些参数
```

例如：

```text
电容电压不能突变
→ 用于去耦和储能
→ 放在芯片电源引脚附近
→ 检查容量、耐压、材质和封装
```

### 7.2 分析 PCB 时区分逻辑和物理

```text
原理图：逻辑连接
PCB：物理位置与铜箔路径
封装：实物尺寸与引脚关系
DRC：规则检查
焊接测试：实物验证
```

避免把其中任意一个步骤视为完整设计。

### 7.3 布线前优先完成合理布局

推荐布局顺序：

```text
板框和安装孔
→ 接口
→ 电源模块
→ MCU 与晶振
→ 去耦电容
→ 通信和保护器件
→ 功率驱动
→ 其他普通元器件
```

合理布局能够显著减少后续绕线和返工。

### 7.4 上电前建立固定检查流程

```text
检查封装与方向
→ 检查焊点
→ 蜂鸣档查导通
→ 检查电源正负极是否短路
→ 限流或低风险上电
→ 测量关键电压
→ 连接负载
→ 功能测试
```

### 7.5 电池使用优先遵守安全阈值

不要以“机器人还能动”为继续使用依据，而应根据：

- 电池整体电压；
- 单节电压；
- BB 响报警；
- 电池外观状态；

决定是否停止使用。

## 8. 今日总结

今天完成了 27RC 硬件基础培训的全部 14 个模块。

首先，明确了硬件组不仅负责焊接，还要完成从需求分析、原理图设计、元器件选型到 PCB 布局布线、焊接和测试的完整流程。硬件系统在机器人中承担电源分配、信号连接、功率驱动和电路保护等任务。

随后学习了 PCB 的基本结构，能够区分基板、铜箔层、阻焊层和丝印层，并理解双层板和四层板的含义。元器件部分学习了电阻、电容、电感、二极管、三极管和 MOS 管，能够说明限流、分压、去耦、滤波、储能、续流和功率驱动等基本作用。

在集成电路部分，学习了 MCU、接口芯片、ADC 和电源管理芯片的分工，理解了 MCU 负责控制、接口芯片负责通信、ADC 负责采集模拟信号、电源管理芯片负责电压转换和稳定供电。进一步认识了晶振、连接器、保险丝、按键和蜂鸣器等常用器件。

PCB 设计部分建立了完整流程：

```text
需求分析
→ 原理图
→ 选型与封装
→ 布局
→ 布线
→ 铺铜
→ DRC
→ 打板
→ 焊接测试
```

同时学习了线宽、线长、最小间距、差分线等长、铺铜、过孔和 DRC 等基本规则，并明确了 DRC 通过不能替代人工核对。

最后学习了 6S 24 V 航模电池的使用要求、BB 响和平衡充电，以及导线焊接、热缩管绝缘和万用表的基本使用。能够说明焊接后应先在断电状态下使用蜂鸣档检查导通和短路，再上电测量关键电压。

今天最重要的整体认识是，可以将机器人硬件系统统一理解为：

```text
电池与电源管理
→ MCU 与传感器
→ 接口和通信
→ 三极管、MOS 管或驱动器
→ 电机、电磁阀和其他负载
```

而 PCB 的任务，就是把这些元器件和功能模块按照正确的电气逻辑和物理规则可靠连接起来。
