# 主从板通信接口（B2 机构）


---

## 链路 & 角色

- **总线**：CAN1（FDCAN1），1Mbps，**扩展帧（29-bit ID）**。
- **主控（本板）**：发指令、收反馈。它从**蓝牙**收操作手按键，转成 CAN1 命令发给你。
- **从板（你）**：接 **左臂 + 右臂 + 灵石夹爪**，收到命令执行并回反馈。

> 从板**做状态机**。主控只做"按键→命令码"映射。

---

## CAN ID 约定（沿用 R2 机构协议，本工程用 CAN1）

> 第 1,2 位=发送端，3,4 位=CAN 路(01=CAN1)，5,6 位=接收端，7,8 位=操作。设备码：1=主控，**5=机构**。

| 方向 | ID 模板 |
| --- | --- |
| 主控 → 机构 | `0x010105xx` |
| 机构 → 主控 | `0x050101xx` |

> 说明：一个从板承载全部机构（左臂+右臂+夹爪），沿用设备 5；操作码区分各机构动作。若后续拆分板子，再按 B1 的按设备代号分 ID。

---

## 命令帧（主控 → 从板）

| 操作码 | CANID | DLC | 数据 | 含义 |
| --- | --- | --- | --- | --- |
| `0x00` | `0x01010500` | 0 | — | 主控自检广播，从板回 `0x05010100` |
| `0x01` | `0x01010501` | 2 | `[M]` | 使能/失能：`0=失能(急停)`，`1=使能` |
| `0x03` | `0x01010503` | 1 | `[D]` | **左臂取块**：吸盘下到取块高度 → 到位开气泵吸附 |
| `0x04` | `0x01010504` | 1 | `[D]` | **左臂放块**：抬到目标层高 → 关气泵放开 |
| `0x05` | `0x01010505` | 1 | `[D]` | **右臂取块**（同左臂） |
| `0x06` | `0x01010506` | 1 | `[D]` | **右臂放块**（同左臂） |
| `0x07` | `0x01010507` | 1 | `[D]` | **左臂放气**（释放吸盘，从板自定义） |
| `0x08` | `0x01010508` | 1 | `[D]` | **右臂放气**（从板自定义） |
| `0x09` | `0x01010509` | 1 | `[D]` | **灵石夹爪张开**（预备姿态） |
| `0x0A` | `0x0101050A` | 1 | `[D]` | **灵石夹爪夹紧**（取灵石） |
| `0x0B` | `0x0101050B` | 1 | `[D]` | **灵石夹爪放开**（放灵石） |
| `0x0C` | `0x0101050C` | 1 | `[D]` | **灵石夹爪回零** |
| `0xEE` | `0x010105EE` | 2 | `[M][错误位]` | 错误警报（从板仅回确认） |
| `0xFF` | `0x010105FF` | 2 | `[R][S]` | 复位（臂回未上电位姿）：`R`=臂选择 `0=全部/1=左臂/2=右臂/3=夹爪`（从板自定义），`S` 保留 0 |

> **上电默认失能**：从板开机后动作命令一律拒绝（回 `0x02 拒绝`），主控必须先发 `0x01 [1]` 使能。

> **数据字段**：动作命令的 `[D]` 字节默认主控发 `0`（预留）。若需带参（如取块的第几档高度），由从板约定后主控补该字节即可；也可按 B1 习惯用 ASCII（`P`=准备/`C`=夹/`R`=放/`Z`=回零）。

## 反馈帧（从板 → 主控）

| 操作码 | CANID | DLC | 数据 | 含义 |
| --- | --- | --- | --- | --- |
| `0x00` | `0x05010100` | 2 | `[状态][E/R]` | 主控自检广播的应答：`状态` `0x00=就绪 / 0x01=忙 / 0x02=未就绪`；`E/R` `bit0=使能` |
| `0x01` | `0x05010101` | 2 | `[M][0]` | 使能/失能确认：`0=失能，1=使能` |
| `0x03` | `0x05010103` | 2 | `[状态][确认]` | 左臂取块执行反馈 |
| `0x04` | `0x05010104` | 2 | `[状态][确认]` | 左臂放块执行反馈 |
| `0x05` | `0x05010105` | 2 | `[状态][确认]` | 右臂取块执行反馈 |
| `0x06` | `0x05010106` | 2 | `[状态][确认]` | 右臂放块执行反馈 |
| `0x07` | `0x05010107` | 2 | `[状态][确认]` | 左臂放气执行反馈 |
| `0x08` | `0x05010108` | 2 | `[状态][确认]` | 右臂放气执行反馈 |
| `0x09` | `0x05010109` | 2 | `[状态][确认]` | 夹爪张开执行反馈 |
| `0x0A` | `0x0501010A` | 2 | `[状态][确认]` | 夹爪夹紧执行反馈 |
| `0x0B` | `0x0501010B` | 2 | `[状态][确认]` | 夹爪放开执行反馈 |
| `0x0C` | `0x0501010C` | 2 | `[状态][确认]` | 夹爪回零执行反馈 |
| `0xFF` | `0x050101FF` | 2 | `[状态][确认]` | 复位执行反馈 |
| `0xEE` | `0x050101EE` | 2 | `[错误类][设备ID]` | 错误反馈：`设备ID`=`0x05`(机构) |

**执行反馈（参考） `[状态][确认]` 取值**：

| `状态` | 含义 |
| --- | --- |
| `0x00` | 已接收，开始执行 |
| `0x01` | 执行完成 |
| `0x02` | 拒绝（忙 / 未使能） |

其中 `确认` = 回显收到的那条命令的操作码（如收到 `0x03` 回 `确认=0x03`）。

**握手**：主控发一条命令 → 从板回一帧确认（开始执行/完成/拒绝）。

## 附：操作序号速查（B2）

| 机构 | 动作 | 操作码 |
| --- | --- | --- |
| 全机构 | 使能/失能 | `0x01` |
| 左臂 | 取块 / 放块 / 放气 | `0x03` / `0x04` / `0x07` |
| 右臂 | 取块 / 放块 / 放气 | `0x05` / `0x06` / `0x08` |
| 灵石夹爪 | 张开 / 夹紧 / 放开 / 回零 | `0x09` / `0x0A` / `0x0B` / `0x0C` |
| 全机构 | 错误警报 | `0xEE` |
| 全机构 | 复位 | `0xFF` |

## Tips

1. 从板用 **CAN1**（`0x010105xx`/`0x050101xx`），按此 ID 基准对接。
2. 动作命令码 + 数据字段 + 反馈位表**已定稿**（主控侧实现见 `Application/Mech/mech.c`）；从板按本表实现 `0x01/0x03..0x0C/0xFF/0xEE`。
3. 按"命令→确认"握手实现收发；状态机在从板这边。
4. **上电默认失能**：主控必须先发 `0x01 [1]`；`0x01 [0]`=急停（电机 0 电流 + 气泵关 + 状态机复位）。
5. 机械臂堆放精度依赖高度标定 + 灵石球不能掉分：联调前先把各档位高度/夹爪对准标定好。
