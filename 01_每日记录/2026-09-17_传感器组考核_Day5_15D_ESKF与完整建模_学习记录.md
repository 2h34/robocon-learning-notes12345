# 二、为什么位置估计必须加入 Velocity

如果只在状态里加入 Position：

\[
p
\]

是不够的。

因为 IMU Accelerometer 给的是加速度层的信息，而不是位置或速度。

物理关系：

\[
\dot p=v
\]

\[
\dot v=a
\]

所以状态链是：

\[
\boxed{
a\rightarrow v\rightarrow p
}
\]

因此位置估计至少需要：

\[
p,\quad v
\]

我的理解：

> 加速度不能直接积分一次得到位置，必须先积分成速度，再由速度积分成位置，因此 15D 状态中必须同时有 \(p\) 和 \(v\)。

---

# 三、Accelerometer 实际测量的不是 World Linear Acceleration

这是今天最重要的新知识之一。

我们固定：

\[
R_{WB}: Body\rightarrow World
\]

重力定义：

\[
g_W=
\begin{bmatrix}
0\\
0\\
-9.81
\end{bmatrix}
\]

Accelerometer 完整 Measurement Model：

\[
\boxed{
a_m
=
R_{WB}^T(a_W-g_W)
+b_a+n_a
}
\]

其中：

- \(a_m\)：Accelerometer Measurement，加速度计读数；
- \(a_W\)：World Frame 中的真实线加速度；
- \(g_W\)：重力向量；
- \(b_a\)：Accelerometer Bias；
- \(n_a\)：Accelerometer Noise。

整理：

\[
\boxed{
a_W
=
R_{WB}(a_m-b_a-n_a)+g_W
}
\]

Nominal Prediction 中使用：

\[
\hat f_B=a_m-\hat b_a
\]

然后：

\[
\boxed{
\hat a_W
=
\hat R_{WB}\hat f_B+g_W
}
\]

其中：

\[
\hat f_B
\]

不是随便定义的中间量，而是：

> **当前 Bias Estimate 修正后的 Body Frame Specific Force（比力）估计值。**

---

# 四、为什么静止时 Accelerometer 仍然读到约 1g

静止状态：

\[
a_W=0
\]

忽略 Bias 和 Noise：

\[
a_m
=
R^T(0-g_W)
\]

如果 Body Frame 和 World Frame 对齐：

\[
g_W=
\begin{bmatrix}
0\\0\\-9.81
\end{bmatrix}
\]

则：

\[
a_m\approx
\begin{bmatrix}
0\\0\\+9.81
\end{bmatrix}
\]

所以：

\[
\boxed{
\|a_m\|\approx1g
}
\]

这说明 Accelerometer 测的不是“物体的真实 World 加速度”，而是 Specific Force。

---

# 五、为什么自由落体时 Accelerometer 接近 0

自由落体时：

\[
a_W=g_W
\]

因此：

\[
a_W-g_W=0
\]

所以：

\[
a_m\approx0
\]

这个例子进一步帮助理解：

> Accelerometer 测的是相对于自由落体的“支撑/非重力加速度”，而不是简单的 \(a_W\)。

# 六、Gravity 的符号不能靠死记

一开始很容易产生的问题：

> 到底应该“加重力”还是“减重力”？

正确做法不是背符号，而是从 Measurement Model 推导。

我们采用：

\[
a_m=R^T(a_W-g_W)+b_a+n_a
\]

所以：

\[
a_W=R(a_m-b_a-n_a)+g_W
\]

Nominal：

\[
\boxed{
\hat a_W
=
\hat R_{WB}(a_m-\hat b_a)+g_W
}
\]

因此这里出现 \(+g_W\)，是由当前 convention 推导出来的。

我的理解：

> 不应该孤立记“重力加还是减”，应该先固定坐标系、\(g_W\) 方向和 Measurement Model，再推公式。

# 七、Accelerometer 单位转换

题目中的 Accelerometer 单位是：

\[
g
\]

但位置积分使用：

\[
p:m,\qquad v:m/s,\qquad a:m/s^2
\]

因此需要：

\[
\boxed{
a_{\text{SI}}=a_g\times9.81
}

学习过程中曾出现一个简单算术错误：

\[

\]

\[
0.2\times9.81=1.962m/s^2
\]

这不是模型理解错误，但提醒实际代码中必须确保单位统一。

# 八、为什么 Position Estimation 必须依赖 Attitude

Accelerometer 输出位于 Body Frame：

\[
a_m\in Body
\]

但 Position 和 Velocity 通常定义在 World Frame：

\[
p,v\in World
\]

因此必须有：

\[
R_{WB}
\]

完成：

\[
Body\ Frame
\rightarrow
World\ Frame
\]

所以位置估计的完整链条是：

\[
\boxed{
Gyroscope
\rightarrow
Attitude
\rightarrow
Body\ Acceleration
\rightarrow
World\ Acceleration
\rightarrow
Velocity
\rightarrow
Position
}
\]

我的理解：

> Position Estimation 并不是单独的“双积分”，它高度依赖姿态是否正确。姿态错误会把 Gravity 错误投影成水平加速度，然后进一步积分成速度和位置漂移。

这也是为什么一个很小的 Attitude Error 也可能造成明显 Position Drift。

# 十、15×15 Covariance Matrix 与 Cross Covariance

\(P\) 可以理解成 5×5 个 3×3 block。

例如：

\[
P_{p\theta}
\]

表示 Position Error 与 Attitude Error 的 Cross Covariance。

\[
P_{v b_a}
\]

表示 Velocity Error 与 Accelerometer Bias Error 的 Cross Covariance。

今天进一步确认了：

> Observation 不一定直接观测某个状态，也可以通过 Cross Covariance 间接修正它。

例如如果：

\[
P_{vp}\neq0
\]

则 Position Observation 可以间接修正 Velocity。

类似：

\[
P_{b_g\theta}\neq0
\]

则 Attitude Observation 可以间接修正 Gyroscope Bias。

我的理解：

> 本质还是根据变量间的关系建立相关性，再通过 Kalman Gain 间接修正没有被直接观测的状态。

# 十三、Accelerometer Bias Random Walk

真实 Bias Model：

\[
\boxed{
\dot b_a=n_{ba}
}
\]

Nominal State 中：

\[
\boxed{
\dot{\hat b}_a=0
}
\]

所以 Error：

\[
\boxed{
\dot{\delta b_a}=n_{ba}
}
\]

一开始可能感觉：

> 一个说 Bias 会变化，一个说 Bias 不变，是不是矛盾？

后来理解：

- True Bias 可以随机漂移；
- Nominal Estimate 在没有 Observation 修正时先保持；
- 两者差异进入 Error State；
- 不确定性通过 \(Q\) / \(P\) 传播。

因此不矛盾。

# 十四、Gyro Bias 与 Accel Bias 的初始化区别

静止时：

\[
\omega_{\text{true}}\approx0
\]

所以：

\[
\boxed{
\hat b_g\approx\text{mean}(\omega_m)
}
\]

Gyro Bias 比较容易直接通过静止均值估计。

Accelerometer 则不同。

静止：

\[
a_W\approx0
\]

所以：

\[
a_m\approx-R_0^Tg_W+b_a+n_a
\]

因此：

\[
\boxed{
\hat b_a
\approx
\bar a_m+R_0^Tg_W
}
\]

但这要求已知/能够估计初始姿态 \(R_0\)。

因此：

> 静止 Accelerometer Measurement 中同时包含 Gravity Projection 和 Bias，不能简单把均值直接当成 \(b_a\)。

这是 Gyro Bias 与 Accelerometer Bias 初始化的重要区别。

# 十五、15D Error Dynamics 的推导主线

## 15.1 Position Error

真实：

\[
\dot p=v
\]

\[
\dot{\hat p}=\hat v
\]

所以：

\[
\boxed{
\dot{\delta p}=\delta v
}
\]

\[

## 15.2 Velocity Error

定义：

\[
\delta v=v-\hat v
\]

所以：

\[
\dot{\delta v}=a_W-\hat a_W
\]

True：

\[
a_W
=
R_{\text{true}}
(a_m-b_a-n_a)+g_W
\]

Nominal：

\[
\hat a_W
=
\hat R(a_m-\hat b_a)+g_W
\]

采用 Right Multiplicative Error：

\[
R_{\text{true}}
=
\hat R\Exp(\delta\theta^\wedge)
\]

且：

\[
b_a=\hat b_a+\delta b_a
\]

定义：

\[
\hat f_B=a_m-\hat b_a
\]

代入：

\[
a_m-b_a-n_a
=
\hat f_B-\delta b_a-n_a
\]

一阶近似：

\[
\Exp(\delta\theta^\wedge)
\approx
I+\delta\theta^\wedge
\]

展开并忽略二阶小量：

\[
\delta\theta^\wedge\delta b_a
\]

\[
\delta\theta^\wedge n_a
\]

得到：

\[
\dot{\delta v}
=
\hat R\delta\theta^\wedge\hat f_B
-\hat R\delta b_a
-\hat Rn_a
\]

利用：

\[
\delta\theta^\wedge\hat f_B
=
-[\hat f_B]_\times\delta\theta
\]

最终：

\[
\boxed{
\dot{\delta v}
=
-\hat R[\hat f_B]_\times\delta\theta
-\hat R\delta b_a
-\hat Rn_a
}
\]

---
