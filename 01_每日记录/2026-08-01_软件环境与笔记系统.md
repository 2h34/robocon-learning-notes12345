## 4. 核心概念

### VS Code

- 是什么：代码和文本编辑器。
- 主要作用：集中查看、编辑和管理项目文件。
- 在Robocon中的用途：编写C/C++、Python和Markdown笔记。

### GCC

- 是什么：C/C++编译工具集。
- 主要作用：将C语言源代码编译成可运行程序。
- 当前用途：编译Windows普通C语言练习程序。

### Git

- 是什么：版本控制工具。
- 主要作用：记录文件修改、比较历史版本并支持回退。
- 在Robocon中的用途：管理代码、笔记和技术文档。

### GitHub

- 是什么：远程仓库托管平台。
- 主要作用：远程备份、同步和协作。
- 注意事项：队内资料不能未经允许上传至公开仓库。

### Markdown

- 是什么：一种轻量级纯文本标记格式。
- 主要作用：记录标题、列表、代码、表格、图片和链接。
- 在Robocon中的用途：整理培训笔记、命令、参数和故障记录。
