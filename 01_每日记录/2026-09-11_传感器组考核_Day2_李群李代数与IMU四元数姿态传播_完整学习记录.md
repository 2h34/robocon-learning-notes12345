# 1. Day 1 关键知识唤醒

## 1.1 \(R_{WB}\) 的方向

已确认：

\[
\mathbf p_W = R_{WB}\mathbf p_B
\]

因此：

\[
\boxed{R_{WB}: B\rightarrow W}
\]

含义是：

> 把 Body Frame（机体系）中的坐标表示转换到 World Frame（世界系）。

这个 convention 今天非常重要，因为后面的：
- \(\dot R=R\omega^\wedge\)
- Body Frame 增量右乘
- Quaternion 右乘

都依赖这个方向约定。

---

## 1.2 Rotation Vector（旋转向量）

Day 1 已知：

\[
\boldsymbol\phi=\theta\mathbf n
\]

其中：

- \(\mathbf n\)：Rotation Axis（旋转轴）
- \(\theta=\|\boldsymbol\phi\|\)：Rotation Angle（旋转角）

因此 Rotation Vector 不是 Euler Angle。

---

## 1.3 Quaternion 乘法为什么不可交换

用户回忆：

> 四元数乘法的向量部分有叉乘项，交换乘法顺序后结果会不同；同时两个乘法顺序代表不同的 Rotation composition。

核心结论：

\[
\boxed{q_1\otimes q_2\neq q_2\otimes q_1}
\]

这不只是代数公式的问题，更根本是：

\[
\boxed{
\text{三维 Rotation composition 一般不可交换}
}
\]

---

## 1.4 \(q^{-1}\) 与 \(-q\)

用户已经能区分：

- \(q^{-1}\)：inverse rotation（反向旋转）
- \(-q\)：和 \(q\) 表示同一个姿态

对单位 Quaternion：

\[
q^{-1}=q^*
\]

而：

\[
q\equiv -q
\]

这是 Unit Quaternion（单位四元数）的 double cover（双覆盖）性质。

# 2. 为什么 Rotation 不能直接“加一个小矩阵”

Rotation Matrix 必须满足：

\[
R^TR=I
\]

以及：

\[
\det(R)=1
\]

如果简单写：

\[
R_{\text{new}}
=
R_{\text{old}}+\Delta R
\]

其中 \(\Delta R\) 是任意小矩阵，那么：

\[
R_{\text{new}}^TR_{\text{new}}
\]

一般不会继续等于 \(I\)。

因此：

> Rotation Matrix 所在空间不是普通的“任意 9 个数的线性空间”。

虽然一个 Rotation Matrix 有 9 个元素，但它真正只有 3 个自由度。

这就是为什么需要：

\[
SO(3)
\leftrightarrow
so(3)
\]

通过局部三维量描述小 Rotation，再通过 Exp 回到合法 Rotation。

# 3. Group（群）与 Lie Group（李群）

## 3.1 Group 的四个核心性质

一个 Group 可以理解为：

> 一个集合 + 一种运算，并满足四条规则。

四条规则：

### ① Closure（封闭性）

两个合法元素做群运算后，仍在集合中。

对 Rotation：

\[
R_1,R_2\in SO(3)
\]

则：

\[
R_1R_2\in SO(3)
\]

---

### ② Associativity（结合律）

\[
(R_1R_2)R_3
=
R_1(R_2R_3)
\]

注意：

> 结合律成立不代表交换律成立。

通常：

\[
R_1R_2\neq R_2R_1
\]

---

### ③ Identity（单位元）

对 Rotation Matrix：

\[
I
\]

满足：

\[
RI=IR=R
\]

---

### ④ Inverse（逆元）

每一个 Rotation 都有反向 Rotation：

\[
R^{-1}=R^T
\]

满足：

\[
RR^{-1}
=
R^{-1}R
=
I
\]

---

# 4. SO(3)：完整三维 Rotation 的集合

**SO(3) = Special Orthogonal Group，三维特殊正交群**

定义：

\[
\boxed{
SO(3)
=
\left\{
R\in\mathbb R^{3\times3}
\mid
R^TR=I,\;
\det(R)=1
\right\}
}
\]

非常重要：

\[
\boxed{
SO(3)\text{ 不是一个 Rotation Matrix}
}
\]

而是：

\[
\boxed{
\text{所有合法三维 Rotation Matrix 的集合}
}
\]

---

## 4.1 为什么叫 Orthogonal（正交）

因为：

\[
R^TR=I
\]

所以 \(R\) 的列向量是单位正交基。

---

## 4.2 为什么叫 Special（特殊）

普通 Orthogonal Matrix（正交矩阵）允许：

\[
\det(R)=\pm1
\]

但三维纯 Rotation 要求：

\[
\det(R)=1
\]

所以取的是 Special Orthogonal Group。

---

## 4.3 Lie Group 的直觉

Lie Group 相比普通 Group，多了一个关键性质：

> 元素之间构成连续、光滑的空间。

因此我们不仅能讨论：
- 一个 Rotation 和另一个 Rotation 怎么复合

还能讨论：
- 一个 Rotation 附近的“无穷小变化”是什么

这就是后面 Lie Algebra（李代数）的来源。

---

# 5. Hat / Wedge Operator 与 Skew-symmetric Matrix

给定三维向量：

\[
\boldsymbol\phi=
\begin{bmatrix}
\phi_x\\
\phi_y\\
\phi_z
\end{bmatrix}
\]

定义：

\[
\boxed{
\boldsymbol\phi^\wedge
=
\begin{bmatrix}
0&-\phi_z&\phi_y\\
\phi_z&0&-\phi_x\\
-\phi_y&\phi_x&0
\end{bmatrix}
}
\]

这个运算叫：

- Hat Operator（帽算子）
- Wedge Operator（楔算子）

---

## 5.1 为什么这个矩阵长这样

用户当时特别问：

> “这里具体是怎么计算的？可以写详细一点吗？现在讲得太浅了。”

于是从叉乘公式重新展开。

设：

\[
\mathbf p=
\begin{bmatrix}
p_x\\
p_y\\
p_z
\end{bmatrix}
\]

则：

\[
\boldsymbol\phi\times\mathbf p
=
\begin{bmatrix}
\phi_y p_z-\phi_z p_y\\
\phi_z p_x-\phi_x p_z\\
\phi_x p_y-\phi_y p_x
\end{bmatrix}
\]

把 \(p_x,p_y,p_z\) 提出来，可以写成：

\[
\begin{bmatrix}
0&-\phi_z&\phi_y\\
\phi_z&0&-\phi_x\\
-\phi_y&\phi_x&0
\end{bmatrix}
\begin{bmatrix}
p_x\\
p_y\\
p_z
\end{bmatrix}
\]

因此：

\[
\boxed{
\boldsymbol\phi^\wedge\mathbf p
=
\boldsymbol\phi\times\mathbf p
}
\]

---

## 5.2 当天一个重要表述修正

用户一开始理解为：

> “\(\phi^\wedge\) 是由叉乘运算得到的反对称矩阵。”

这个说法接近但不够准确。

更准确是：

\[
\boxed{
\phi^\wedge
\text{ 是“与 }\phi\text{ 做叉乘”这个线性算子的矩阵表示}
}
\]

它本身不是一次叉乘的“结果”。

---

## 5.3 为什么叫 Skew-symmetric Matrix（反对称矩阵）

因为：

\[
(\phi^\wedge)^T
=
-\phi^\wedge
\]

所以它是反对称矩阵。

一般 3×3 反对称矩阵都可以写成：

\[
\begin{bmatrix}
0&-c&b\\
c&0&-a\\
-b&a&0
\end{bmatrix}
\]

可见只有三个独立变量：

\[
a,b,c
\]

因此 3×3 反对称矩阵也是 3 自由度。

这和三维 Rotation 只有 3 自由度相匹配。

---

# 6. Vee Operator

Vee Operator 是 wedge / hat 的逆运算：

\[
\phi^\wedge
\overset{\vee}{\longrightarrow}
\phi
\]

因此：

\[
\boxed{
\mathbb R^3
\overset{\wedge}{\longrightarrow}
so(3)
}
\]

以及：

\[
\boxed{
so(3)
\overset{\vee}{\longrightarrow}
\mathbb R^3
}
\]

---

# 7. 为什么 so(3) 是反对称矩阵

这部分是今天最重要的推导之一。

Rotation Matrix 随时间变化：

\[
R(t)
\]

但任何时刻都必须保持合法：

\[
R(t)^TR(t)=I
\]

对时间求导：

\[
\frac{d}{dt}(R^TR)=0
\]

根据乘积求导：

\[
\dot R^TR+R^T\dot R=0
\]

令：

\[
A=R^T\dot R
\]

则：

\[
A^T
=
\dot R^TR
\]

所以：

\[
A^T+A=0
\]

因此：

\[
\boxed{
A^T=-A
}
\]

也就是：

\[
\boxed{
R^T\dot R
\text{ 必须是反对称矩阵}
}
\]

因此可以写：

\[
\boxed{
R^T\dot R
=
\omega^\wedge
}
\]

从而：

\[
\boxed{
\dot R
=
R\omega^\wedge
}
\]

---

## 7.1 今天这里出现的一个核心误区

用户一开始总结：

> “Rotation Matrix 的变化率是反对称矩阵。”

这个说法不准确。

正确的是：

\[
\boxed{
R^T\dot R
\text{ 是反对称矩阵}
}
\]

而不是：

\[
\dot R
\]

本身一定反对称。

这是今天一个必须记住的概念边界。

---

# 8. so(3) 到底是什么

严格一点：

\[
\boxed{
so(3)
=
\{\Omega\in\mathbb R^{3\times3}
\mid
\Omega^T=-\Omega\}
}
\]

也就是：

> 所有 3×3 反对称矩阵组成的 Lie Algebra（李代数）。

入门直觉可以理解为：

> \(SO(3)\) 在单位 Rotation \(I\) 附近的局部线性空间。

或者：

> 描述局部 Rotation change 的三维线性空间。

---

## 8.1 “so(3) 是变化率”为什么不够准确

用户最终验收时说：

> “so(3) 可以看作一个和变化率相关的量。”

这在当前推导背景下有一定道理，但不能直接等号。

因为：

\[
\omega^\wedge\in so(3)
\]

这里 \(\omega\) 是 Angular Velocity，所以确实与变化率有关。

但：

\[
\phi^\wedge\in so(3)
\]

这里 \(\phi=\theta n\) 是 Rotation Vector，表示累计 Rotation，不是角速度。

所以：

\[
\boxed{
so(3)\text{ 本身不是“变化率”}
}
\]

它是一个数学空间。

具体元素的物理意义取决于上下文。

---

# 9. Rotation Vector 与 so(3)

Rotation Vector：

\[
\phi=\theta n
\]

通过 wedge：

\[
\phi
\rightarrow
\phi^\wedge
\]

得到一个 so(3) 元素。

但是：

\[
\boxed{
\phi^\wedge
\text{ 不是 Rotation Matrix}
}
\]

它不能直接拿来代替 \(R\)。

要从局部旋转参数得到完整 Rotation，需要：

\[
\boxed{
Exp
}
\]

# 10. Exponential Map（指数映射）

定义：

\[
\boxed{
R
=
\operatorname{Exp}(\phi^\wedge)
}
\]

它完成：

\[
\boxed{
so(3)
\rightarrow
SO(3)
}
\]

---

## 10.1 Matrix Exponential（矩阵指数）

矩阵指数不是对每个元素分别求指数。

定义：

\[
e^A
=
I+A+\frac{A^2}{2!}
+\frac{A^3}{3!}
+\cdots
\]

因此：

\[
\operatorname{Exp}(\phi^\wedge)
=
I+\phi^\wedge
+\frac{(\phi^\wedge)^2}{2!}
+\cdots
\]

---

# 11. Rodrigues Formula（罗德里格斯公式）

令：

\[
\phi=\theta n
\]

且：

\[
\|n\|=1
\]

通过展开矩阵指数，可以得到：

\[
\boxed{
R
=
I
+\sin\theta\,n^\wedge
+(1-\cos\theta)(n^\wedge)^2
}
\]

也可以写成：

\[
\boxed{
R
=
I
+
\frac{\sin\theta}{\theta}\phi^\wedge
+
\frac{1-\cos\theta}{\theta^2}
(\phi^\wedge)^2
}
\]

今天重点不是背公式，而是理解：

\[
\boxed{
Rotation\ Vector
\rightarrow
so(3)
\rightarrow
Exp
\rightarrow
合法 Rotation Matrix
}
\]

---

# 12. Exp 为什么会自然出现

用户这里曾追问：

> “为什么有这个条件？为什么 Exp 会这样出现？”

于是从运动学微分方程推导。

已知：

\[
R^T\dot R
=
\omega^\wedge
\]

得到：

\[
\dot R
=
R\omega^\wedge
\]

假设短时间内：

\[
\omega=\text{constant}
\]

则：

\[
\omega^\wedge
\]

也是常量。

于是：

\[
\dot R=RA
\]

其中：

\[
A=\omega^\wedge
\]

它的解为：

\[
R(t)
=
R(0)e^{At}
\]

因此：

\[
R(t)
=
R(0)e^{\omega^\wedge t}
\]

如果：

\[
R(0)=I
\]

则：

\[
R(t)
=
e^{\omega^\wedge t}
\]

再定义：

\[
\phi=\omega t
\]

得到：

\[
\boxed{
R
=
\operatorname{Exp}(\phi^\wedge)
}
\]

---

## 12.1 今天最重要的理解之一

\[
\boxed{
Exp
\text{ 不是人为硬规定出来的}
}
\]

而是：

> Rotation kinematics（旋转运动学）微分方程的自然解。

# 13. 小角度近似

当：

\[
\|\phi\|\ll1
\]

有：

\[
\sin\theta\approx\theta
\]

\[
1-\cos\theta\approx\frac{\theta^2}{2}
\]

因此：

\[
R
\approx
I+\phi^\wedge
+\frac12(\phi^\wedge)^2
\]

如果只保留一阶：

\[
\boxed{
R\approx I+\phi^\wedge
}
\]

注意：

> 这是 small-angle approximation（小角度近似），不是严格恒等式。

---

# 14. Logarithmic Map（对数映射）

Log 做 Exp 的反方向：

\[
\boxed{
SO(3)
\rightarrow
so(3)
}
\]

即：

\[
R
\xrightarrow{Log}
\phi^\wedge
\xrightarrow{\vee}
\phi
\]

直觉：

> 已知一个完整 Rotation，找出“它相当于绕哪根轴转了多少角度”。

---

# 15. 为什么

\[
\operatorname{tr}(R)=1+2\cos\theta
\]

用户专门问过：

> “这个公式怎么来的？”

从 Rodrigues Formula：

\[
R=
I+\sin\theta n^\wedge
+(1-\cos\theta)(n^\wedge)^2
\]

取 trace：

\[
tr(R)
=
tr(I)
+
\sin\theta\,tr(n^\wedge)
+
(1-\cos\theta)tr((n^\wedge)^2)
\]

分别计算：

\[
tr(I)=3
\]

因为反对称矩阵对角线为 0：

\[
tr(n^\wedge)=0
\]

又有：

\[
(n^\wedge)^2
=
nn^T-I
\]

于是：

\[
tr((n^\wedge)^2)
=
tr(nn^T)-tr(I)
\]

而：

\[
tr(nn^T)=n^Tn=1
\]

所以：

\[
tr((n^\wedge)^2)
=
1-3=-2
\]

最终：

\[
tr(R)
=
3-2(1-\cos\theta)
\]

即：

\[
\boxed{
tr(R)
=
1+2\cos\theta
}
\]

因此：

\[
\boxed{
\theta
=
\arccos
\left(
\frac{tr(R)-1}{2}
\right)
}
\]

---

# 16. Log 得到的不是“旋转轴”，而是 Rotation Vector

最终验收时问：

\[
\delta\theta
=
Log(R_1^{-1}R_2)^\vee
\]

用户最初回答：

> “旋转轴？”

这里需要纠正：

\[
\boxed{
\delta\theta
=
\theta n
}
\]

它是完整 Rotation Vector。

其中：

\[
\frac{\delta\theta}{\|\delta\theta\|}
\]

才是 Rotation Axis。

而：

\[
\|\delta\theta\|
\]

才是 Rotation Angle。

所以：

\[
\boxed{
Log + vee
\text{ 得到的是“轴 + 角”的完整三维旋转向量}
}
\]

# 17. Relative Rotation（相对旋转）

如果：

\[
R_2
=
R_1\Delta R
\]

则：

\[
\boxed{
\Delta R
=
R_1^{-1}R_2
}
\]

其几何意义：

> 从姿态 \(R_1\) 旋转到姿态 \(R_2\) 所需要的那一段 Rotation。

---

# 18. 为什么局部 Rotation Increment 是右乘

这是今天用户追问最多的概念之一。

固定：

\[
R_{WB}
\]

表示：

\[
B\rightarrow W
\]

如果当前 Body Frame 是 \(B_1\)，下一时刻是 \(B_2\)。

定义局部增量：

\[
\Delta R_B
=
R_{B_1B_2}
\]

它表示：

\[
B_2\rightarrow B_1
\]

一个向量坐标链：

\[
p_{B_2}
\xrightarrow{\Delta R_B}
p_{B_1}
\xrightarrow{R_{WB_1}}
p_W
\]

因此：

\[
p_W
=
R_{WB_1}\Delta R_B p_{B_2}
\]

所以：

\[
\boxed{
R_{WB_2}
=
R_{WB_1}\Delta R_B
}
\]

也就是：

\[
\boxed{
Body-local increment
\Rightarrow
右乘
}
\]

---

# 19. World-global Increment 为什么左乘

如果增量是在固定 World Frame 中表达，那么相当于：

> 先把旧姿态放到 World，再在 World axes 上施加一段 Rotation。

于是：

\[
\boxed{
R_{\text{new}}
=
\Delta R_W R_{\text{old}}
}
\]

所以在当前 convention 下：

\[
\boxed{
当前 / Body / local
\Rightarrow
右乘
}
\]

\[
\boxed{
固定 / World / global
\Rightarrow
左乘
}
\]

---

## 19.1 必须记住的边界

这不是绝对真理。

它依赖：
- 你定义的是 \(R_{WB}\) 还是 \(R_{BW}\)
- active rotation / passive coordinate transform convention
- 增量在哪个 Frame 表达

更根本的判断方法是：

\[
\boxed{
\text{看坐标链和增量表达 Frame}
}
\]

而不是死背“gyro 一定右乘”。

---

# 20. Exp / Log 与 Quaternion 的关系

同一个 Rotation Vector：

\[
\phi=\theta n
\]

可生成：

\[
R
=
Exp(\phi^\wedge)
\]

也可生成：

\[
q
=

两者：

# 21. Quaternion 为什么出现半角

Quaternion 旋转向量时：

\[
p'
=
q\otimes p\otimes q^{-1}
\]

其中 \(q\) 内部含：

\[
\sin(\theta/2),\qquad\cos(\theta/2)
\]

经过左右两次 Quaternion multiplication，会通过二倍角关系产生：

\[
\sin\theta,\qquad\cos\theta
\]

例如：

\[
2\sin\frac\theta2\cos\frac\theta2
=
\sin\theta
\]

以及：

\[
\cos^2\frac\theta2
-
\sin^2\frac\theta2
=
\cos\theta
\]

因此：

\[
\boxed{
q\text{ 用半角编码，但代表完整的 }\theta\text{ Rotation}
}
\]

# 25. Bias 与 Noise 的区别

## 25.1 Bias（零偏）

直觉：

> 测量中心整体偏离真实值。

例如实际静止：

\[
\omega_{\text{true}}=0
\]

但数据长期围绕：

\[
0.02\,rad/s
\]

波动。

这时：

\[
0.02
\]

更像 Bias。

---

## 25.2 Noise（噪声）

Noise 更像：

> 每一帧在 Bias 周围随机上下波动。

所以可以记为：

\[
\boxed{
Bias=\text{中心偏移}
}
\]

\[
\boxed{
Noise=\text{随机抖动}
}
\]

# 26. 初始静止为什么能估计 Gyro Bias

题目给出的一个关键条件：

> 机器人初始静止，可以利用前若干帧估计 Gyroscope Bias。

静止时：

\[
\omega_{\text{true}}
\approx0
\]

所以：

\[
\omega_m
\approx
b_g+n_g
\]

对前 \(N\) 帧平均：

\[
\boxed{
\hat b_g
\approx
\frac1N
\sum_{i=1}^{N}\omega_m^{(i)}
}
\]

如果 Noise 近似零均值，那么：

\[
\frac1N\sum n_g
\rightarrow0
\]

所以平均值更接近 Bias。

## 26.1 当天一个表述修正

用户最初说：

> “真实的 bias 会受 noise 影响，noise 有时正有时负，多帧平均后减小 noise。”

其中后半句正确，但前半句不够精确。

更准确：

> 测量值中同时叠加 Bias 与 Noise；多帧平均削弱 Noise 后，平均值更接近 Bias。

# 27. Angular Velocity → Rotation Vector Increment

Bias 补偿后：

\[
\hat\omega
=
\omega_m-\hat b_g
\]

如果短时间 \(\Delta t\) 内：

\[
\hat\omega
\]

近似恒定，则：

\[
\boxed{
\Delta\theta
=
\hat\omega\Delta t
}
\]

更明确写成向量：

\[
\boxed{
\Delta\boldsymbol\theta
=
\hat{\boldsymbol\omega}\Delta t
}
\]

单位检查：

\[
rad/s\times s=rad
\]

所以：

\[
\Delta\boldsymbol\theta
\]

已经不是 Angular Velocity，而是：

\[
\boxed{
Rotation\ Vector\ Increment（旋转向量增量）
}
\]

---

## 27.1 它的方向和模长

方向：

\[
\frac{\Delta\theta}{\|\Delta\theta\|}
\]

表示这段时间内的 Rotation Axis。

模长：

\[
\|\Delta\theta\|
=
\|\omega\|\Delta t
\]

表示这段时间内转过的 Rotation Angle。

---

## 27.2 用户当天的理解

用户说：

> “角速度累积一段时间以后就变成了位移，描述姿态。”

这个理解方向正确，但更准确应该叫：

\[
\boxed{
Angular\ Displacement（角位移）
}
\]

或：

\[
\boxed{
Rotation\ Increment（旋转增量）
}
\]

并且它不是“绝对姿态”，而是：

> 相邻两个时刻之间的姿态变化量。

\boxed{

# 31. Quaternion Differential Equation

从离散更新开始：

\[
q(t+\Delta t)
=
q(t)\otimes\Delta q
\]

当：

\[
\Delta t\rightarrow0
\]

有：

\[
\Delta\theta
=
\omega\Delta t
\]

Quaternion Increment：

\[
\Delta q
=
\begin{bmatrix}
n\sin(\Delta\theta/2)\\
\cos(\Delta\theta/2)
\end{bmatrix}
\]

小角度下：

\[
\sin(\Delta\theta/2)
\approx
\frac{\Delta\theta}{2}
\]

\[
\cos(\Delta\theta/2)
\approx1
\]

而：

\[
n\Delta\theta
=
\omega\Delta t
\]

所以：

\[
\Delta q
\approx
\begin{bmatrix}
\frac12\omega\Delta t\\
1
\end{bmatrix}
\]

也可写成：

\[
\Delta q
\approx
q_I
+
\frac12
\begin{bmatrix}
\omega\\
0
\end{bmatrix}
\Delta t
\]

于是：

\[
q(t+\Delta t)
\approx
q(t)\otimes
\left(
q_I
+
\frac12
[\omega,0]\Delta t
\right)
\]

得到：

\[
q(t+\Delta t)
\approx
q(t)
+
\frac12
q(t)\otimes[\omega,0]\Delta t
\]

两边减 \(q(t)\)，除以 \(\Delta t\)，再令：

\[
\Delta t\rightarrow0
\]

得到：

\[
\boxed{
\dot q
=
\frac12
q\otimes[\omega_B,0]
}
\]

# 32. 为什么 \([\omega_B,0]\) 在右边

因为：

\[
\omega_B
\]

是在 Body Frame 中表达。

与矩阵形式：

\[
\dot R
=
R\omega_B^\wedge
\]

对应。

因此 Quaternion 形式也是：

\[
\boxed{
\dot q
=
\frac12q\otimes[\omega_B,0]
}
\]

若是：

\[
\omega_W
\]

在 World Frame 中表达，则形式会对应：

\[
\boxed{
\dot q
=
\frac12[\omega_W,0]\otimes q
}
\]

# 33. Unit Quaternion Identity

题目 Quaternion 顺序是：

\[
[q_x,q_y,q_z,q_w]
\]

也就是 vector first、\(w\) last。

单位 Quaternion：

\[
\boxed{
q_I=
[0,0,0,1]
}
\]

它表示：

\[
\theta=0
\]

因此：

\[
q\otimes q_I=q
\]

以及：

\[
q_I\otimes q=q
\]

用户当天专门问：

> “为什么这里 \(q\otimes q_I=q\) 成立？”

答案是：

> \(q_I\) 是 Quaternion multiplication 的 Identity Element（单位元）。

# 35. Discrete Quaternion Integration：方法 A

方法 A：

\[
\Delta\theta
=
\omega\Delta t
\]

先构造 Quaternion Increment：

\[
\Delta q
\]

再：

\[
\boxed{
q_{k+1}
=
q_k\otimes\Delta q
}
\]

它的直觉：

> 先算出这一小段时间实际转过的有限 Rotation，再将它复合到当前姿态。

这是比较贴近 Rotation geometry 的方法。

# 36. Discrete Quaternion Integration：方法 B

连续运动学：

\[
\boxed{
\dot q
=
\frac12q\otimes[\omega,0]
}
\]

使用 Forward Euler Integration（前向欧拉积分）：

\[
\boxed{
q_{k+1}
\approx
q_k+\dot q_k\Delta t
}
\]

代入：

\[
\boxed{
q_{k+1}
\approx
q_k
+
\frac12q_k\otimes[\omega_k,0]\Delta t
}
\]

# 37. Forward Euler 为什么成立

用户当时说不太理解：

> “为什么要这样做？”

先从普通变量：

\[
x(t)
\]

导数：

\[
\dot x
=
\frac{dx}{dt}
\]

在很短 \(\Delta t\) 内，如果变化率近似不变：

\[
\Delta x
\approx
\dot x\Delta t
\]

所以：

\[
\boxed{
x(t+\Delta t)
\approx
x(t)+\dot x(t)\Delta t
}
\]

Quaternion 也一样：

\[
\boxed{
q(t+\Delta t)
\approx
q(t)+\dot q(t)\Delta t
}
\]

这就是 Forward Euler。

---

# 38. 方法 A 与方法 B 的关系

最终验收中用户总结：

> 方法 A 是离散的；方法 B 是从连续公式出发。  
> 当 \(\Delta t\) 很小时，方法 A 中 \(\sin\)、\(\cos\) 可以做小角度近似，方法 B 的 Euler 也是一阶近似，所以两者会得到相同的一阶形式。

这个理解基本正确。

更准确：

> 它们不是两套不同的姿态估计算法，而是同一个 Quaternion kinematics 的两种传播表达。

## 38.1 为什么小 \(\Delta t\) 时二者一致

方法 A：

\[
\Delta q
=
\begin{bmatrix}
n\sin(\Delta\theta/2)\\
\cos(\Delta\theta/2)
\end{bmatrix}
\]

小角度：

\[
\sin(\Delta\theta/2)
\approx
\frac{\Delta\theta}{2}
\]

\[
\cos(\Delta\theta/2)
\approx1
\]

所以：

\[
\Delta q
\approx
\begin{bmatrix}
\frac12\omega\Delta t\\
1
\end{bmatrix}
\]

代入：

\[
q_{k+1}
=
q_k\otimes\Delta q
\]

得到：

\[
q_{k+1}
\approx
q_k
+
\frac12
q_k\otimes[\omega,0]\Delta t
\]

这正是 Forward Euler 的结果。

# 39. 一个重要纠正：Quaternion Differential Equation 不是小步长近似

用户当时回答：

> “因为方法 B 的公式就是在 \(\Delta t\) 很小的时候推导出来的。”

需要精确区分：

\[
\boxed{
\dot q
=
\frac12q\otimes[\omega,0]
}
\]

是：

\[
\boxed{
连续时间 Quaternion kinematics
}
\]

它本身不是“只有小 \(\Delta t\) 才成立”。

真正依赖 small \(\Delta t\) 的是：

\[
q_{k+1}
\approx
q_k+\dot q_k\Delta t
\]

这个 Forward Euler 一阶近似。

# 40. 为什么 Quaternion 更新后要 Normalize

合法 Rotation Quaternion 满足：

\[
\boxed{
\|q\|=1
}
\]

理论上的精确运动学会保持单位长度。

但计算机中存在：

- Numerical Integration Error（数值积分误差）
- Floating-point Error（浮点误差）

尤其 Forward Euler：

\[
q_{k+1}
\approx
q_k+\dot q_k\Delta t
\]

本质是：

> 沿当前切线方向直走一小步。

而 Unit Quaternion 所在的空间不是一条直线，所以结果会稍微跑出：

\[
\|q\|=1
\]

的约束。

因此：

\[
\boxed{
q
\leftarrow
\frac{q}{\|q\|}
}
\]

---

## 40.1 二维圆的类比

在单位圆：

\[
x^2+y^2=1
\]

当前点：

\[
(1,0)
\]

如果沿切线直接走：

\[
(1,0.1)
\]

那么长度：

\[
\sqrt{1.01}>1
\]

已经不在圆上。

Quaternion 的 Euler step 类似：

> 沿切线近似走一步后，需要重新投回合法约束面。

---

## 40.2 Normalize 的本质

不是：

> “重新估计一个新的姿态”

而是：

\[
\boxed{
\text{把数值近似结果重新投回 Unit Quaternion constraint}
}
\]

---

# 41. 为什么方法 A 也常常 Normalize

理论上：

\[
\|q_k\|=1
\]

\[
\|\Delta q\|=1
\]

则：

\[
\|q_k\otimes\Delta q\|=1
\]

所以方法 A 数学上会保持单位长度。

但实际代码仍有：

- 浮点误差
- 三角函数数值误差
- 长时间累计误差

所以实际工程常继续：

\[
q
\leftarrow
\frac q{\|q\|}
\]

作为数值保险。

# 42. 为什么纯 Gyroscope Integration 会 Drift

Bias 补偿后：

\[
\hat\omega
=
\omega_m-\hat b_g
\]

但实际不可能完全没有误差：

\[
\hat\omega
=
\omega_{\text{true}}
+
\delta\omega
\]

姿态是由 Angular Velocity 积分得到：

\[
\theta
=
\int\omega dt
\]

所以误差也会被积分：

\[
\boxed{
\delta\theta
=
\int\delta\omega dt
}
\]

---

## 42.1 Residual Bias 为什么特别危险

如果残余 Bias：

\[
\delta b_g
\]

在一段时间内近似常量：

\[
\boxed{
\delta\theta(t)
\approx
\delta b_g t
}
\]

所以：

> 一个很小的角速度误差，持续很久以后，也会变成明显姿态误差。

---

## 42.2 用户最终理解

用户回答：

> “陀螺仪测量角速度，如果角速度一直存在误差，误差会随时间一直累积积分，最终会造成明显的 drift。”

这个理解正确。

# 54. 最终一句话总结

> 陀螺仪并不直接输出姿态，而是输出 Body Frame 下的 Angular Velocity。我们先减去 Gyroscope Bias，用 timestamp 得到真实 \(\Delta t\)，再通过 \(\Delta\theta=\omega\Delta t\) 得到 Rotation Vector Increment，转成 Quaternion Increment，并在当前 \(q_{WB}\) convention 下右乘到当前姿态；由于角速度误差也会被积分，所以纯 Gyroscope propagation 会产生 Drift，这就是后续必须引入 Observation correction 和 EKF / ESKF 的原因。
