# 方块操作机构程序框架（当前版）

## 1. 程序分层

```text
操作手按键 / 上层控制
        ↓
PickBlockTask / PlaceBlockTask
        ↓
BlockArm / BlockVacuum
        ↓
DJI 电机、ZDrive 电机、真空气路
```

- `Task`：负责把多个固定动作按顺序串起来。
- `BlockArm`：负责双电机机械臂的移动、保持、微调、停止和复位。
- `BlockVacuum`：负责吸盘的吸附与释放。
- 电机层：负责位置模式、CAN 通信和电机反馈。

Task 不直接控制电机角度；机械臂的双电机目标都封装在 `BlockArm` 内。

## 2. 取块任务流程

```text
启动低位/高位取块
        ↓
机械臂自动到取块粗定位姿态
        ↓
操作手观察并人工微调末端
        ↓
操作手确认吸附
        ↓
吸盘确认吸住方块
        ↓
机械臂自动回 Safe 搬运姿态
        ↓
取块完成
```

取块过程中，操作手可随时停止：

```text
停止 Task
→ 机械臂保持当前位置
→ Task 中断

后续调用复位
→ 机械臂回 Safe
→ 机械臂 READY
→ 可重新开始取块
```

## 3. 放块任务流程

```text
选择底层 / 第一层 / 第二层放块
        ↓
机械臂自动到对应放块粗定位姿态
        ↓
操作手观察并人工微调
        ↓
操作手确认释放
        ↓
吸盘确认方块已释放
        ↓
机械臂自动回 Safe 搬运姿态
        ↓
放块完成
```

## 4. BlockArm 状态

```text
UNHOMED  未归零
HOMING   正在归零
READY    已归零、可开始新动作
MOVING   自动运动或人工微调中
REACHED  已到达当前目标
STOPPED  操作手停止后保持当前位置
FAULT    机构故障
```
